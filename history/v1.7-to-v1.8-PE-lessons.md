## 二、PE 哲学三大修正(核心沉淀)

### 修正 1:路由表 → AI 自决定 + suggested defaults

**v1.7(R-134 之前)**
```
§2 Style Routing 7 个 font_family × keyword 表 + Conflict priority
STYLE_PRESETS: font_family → radius/density/hero_shader
```

**v1.8**
```
§1 Identity & Mood
The AI decides accent hue, mode, Hero shader from user's brief.
Shader choice is flexible — any shader can fit any mood with the right color palette.
Suggested defaults (NOT hard rules):
- Growth/sales/celebration → Light, hue 30–55, GrainGradient
- Tech/SaaS/engineering → Dark, hue 240–270, Dithering
- Premium/ceremony/theatrical → Dark, hue 35–50, MeshGradient
- Health/sustainability/organic → Light, hue 140–165, GrainGradient
- Generic/unclear → Light, hue 240, GrainGradient
```

**经验**:**给 AI 软建议 + 灵活替代 > 硬路由表**。弱模型 doubao 在硬路由下被锁死,实际场景超出 7 family 时退化为 fallback。**Suggested defaults 模式让 AI 既有锚点又有灵活度**,实际跨场景适配更好。

### 修正 2:严控工程化 → 适度工程化(完整 JSX inline)

**v1.7 之前 PE 红线(R-130/R-133/R-134)**:
- 不写完整 React snippet / JSX example
- 不写 完整 className 串 / hex 颜色
- AnimateNumber + Hero shader 是工程实现唯一例外

**v1.8 修正:装饰性元素提供完整 JSX**
- §2 Token template 含 shadcn compat tokens(--card / --popover / --secondary / --muted / --accent / --destructive / --input / --ring / --radius / --font-sans)inline
- §8 Shader examples 提供 4 个完整 JSX(含 hex 颜色:#F7F6F3 / #5A5E6B 等)
- §9 Components 提供 parseDisplayValue + AnimateNumber / DeltaIndicator / SpotlightGradient / ChartTooltipCard / Chapter Opener / OutroSignature 完整 JSX
- §9 Charts 提供完整 AreaChart 实例(含 defs/CartesianGrid/XAxis/YAxis/Area/Tooltip 全 props)

**经验**:**装饰性元素完整 JSX inline > design 语言描述**。doubao 直接照搬比"推导"更准。**Design prompt 不仅是约束,也是 reference implementation**。

### 修正 3:override 补丁 → 完全禁用 + 替代

**v1.7 R-134 round 3 V7-3 解决"shadcn ring shadow 黑边"**:
```
shadcn <Card> / <Tabs> / <Separator> MUST add ring-0
alongside border-0 shadow-none
```

**v1.8 升级**:
```
§5: Do NOT use shadcn <Card> component for metric cells or KPI clusters.
    Card carries default border and shadow styles.
    Use plain <div> with bg-[var(--surface-l2)] + rounded-[12px] + p-6 instead.

§9: Do NOT use ChartTooltipContent (default border/shadow can't be reliably overridden).
    Use ChartTooltipCard instead.
```

**经验**:**完全禁用 + 提供替代 > 打补丁 override**。v1.7 的 override 三件套(ring-0 + border-0 + shadow-none)对 doubao 太复杂,直接说"别用这个组件"更彻底。

## 三、新增内容(沉淀价值最高的 6 个)

### A. Multi-metric font-size rule(§3 critical for readability)

```
| Columns | Max number scale | Example |
| 1 (Hero focal) | Display 64/96/140 | Single anchor |
| 2 | Section Primary 34/44/56 | Comparison pair |
| 3–4 | Section Secondary 26/32/40 | KPI row |
| ≥5 | 20/24/32 | Dense cluster |

Each cell: min-w-0 + whitespace-nowrap, gap-4 between cells.
If risks overflow, drop one more tier. Overlapping numbers never acceptable.
```

**经验**:**doubao 实测 KPI cells 数字 overlap 是高频问题**,加 column-count → max-scale 表能根治。R-134 我们漏抓这一项(v1.5 → v1.7 都没解)。

### B. Type scale 加 md (≥768px) 中间档

v1.7 只 lg / mobile,v1.8 加 md:
```
| Display Number | lg 140 | md 96 | mobile 64 |
| Hero Title | lg 88 | md 68 | mobile 44 |
| Section Primary | lg 56 | md 44 | mobile 34 |
...
```

**经验**:响应式分档更细,doubao mobile-only 跳到 lg 不再跨度过大,中间窗口体验也合理。

### C. GodRays 第 4 个 shader

v1.7 仅 mesh / grain / dithering;v1.8 加 GodRays(戏剧/能量/仪式 spotlight)。

**经验**:shader 工具箱扩展,实际场景超出原 3 个 shader 时不再 fallback。

### D. Entrance vs What NOT 二分清晰枚举

```
What to animate (granular decorative only):
- Hero text rows (stagger)
- KPI cells
- chapter opener
- outro flourish

What NOT to animate:
- <section> wrap motion.div with initial:opacity:0
- Layout props (width, height, padding, margin, gap)
- useScroll / useTransform / scrollYProgress
- ScrambleText / Typewriter / character-level reveal
- Bar chart bars rising from zero
- useInView() + conditional animate
```

**经验**:**正负并列 + 具体 enumeration > 抽象 design 语言**。R-134 我们(P1 砍 §10 重复条)曾经反过来删枚举改 design 语言,v1.8 证明 enumeration 对弱模型更易理解(只要不是过度教学)。

### E. ChartContainer 强制 wrap + ChartTooltipContent 完全禁用

```
Every chart MUST be wrapped in <ChartContainer config={...}>
- 不能 bare <AreaChart>/<BarChart>/<LineChart>
- 不用 shadcn <ChartTooltip> 或 <ChartTooltipContent>
- 用 custom ChartTooltipCard with wrapperStyle={{ outline:'none' }}
```

**经验**:**框架级强制(wrap) + 完全禁用替代(override)**,比 R-134 V6-2 "ChartTooltipCard inline strict" 更上游。

### F. Hero layout adaptation for images

```
§8 Hero Layout adaptation rules:
1. User mentions images/photos/图片/商品图/产品图/封面
   → Asymmetric Split with image region (1-4 images grid)
   → Images MUST appear — never ignore user-requested visuals
2. Data-heavy brief, no images
   → Asymmetric Split with focal number leading left
3. Minimal data, ceremonial tone
   → Full-bleed Monolith or Typographic Field
```

**经验**:**user intent → layout decision 映射明确**,doubao 不再忽略 image request(R-134 我们没覆盖这一项)。

## 五、对比 R-130/R-133/R-134 决策 lessons

| R-130 ~ R-134 严格 PE 哲学 | v1.8 修正 | Lessons |
|------|------|---------|
| design prompt 严控工程化,不写完整 JSX | 装饰性元素**完整 JSX inline** 是必要的 | **PE 流程教条化风险**:严格"不工程化"在 design prompt 上下文是反生产力 |
| ChapterStamp 装饰 6 variants 保留 | 简化为通用 Chapter Opener + design rule | **过度精雕**:6 variants 是 R-90/R-92 之前积累的,但实际 weak model 用不到那么细 |
| shadcn 用法需要 override default styling | **直接禁用** shadcn 组件 + 用 plain div | **patch 思维 vs 重构思维**:override 复杂多步骤,doubao 错率高;禁用 + 替代一步到位 |
| HARD GATE 强调 + Match-and-refuse 严格表达 | 简洁 bullet + JSX example,**密度比强调更重要** | **强调通胀**:HARD GATE / MUST / NEVER 用多了就稀释;bullet enumeration 更清晰 |
| 双路 review (Codex + Opus 4.6 PE) + Codex final | 跟研发实测一轮修一轮 | **实测 > PE review**:PE review 可发现 prompt 语言层面问题,但 doubao 实际行为只有实测可暴露 |
