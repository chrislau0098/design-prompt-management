## 1. Brand & Style

Default vibe: **Restrained · Precise · Single-hue · Flat**.

Proposition: a parameterized campaign-report base. Style dials route from user keywords or explicit visual direction; advanced dials auto-derive from STYLE_PRESETS[font_family] when not specified. Defaults: `mode=light` · brand color blue (per §3 presets) · `lightness=0` · `font=geometric`. Cards lean on surface fill and spacing for separation — edges stay minimal.

Style presets (font_family → advanced dials):

| font_family | radius | density | hero_shader |
|-------------|--------|---------|-------------|
| geometric | sharp | balanced | mesh |
| editorial | sharp | sparse | grain |
| technical | crisp | dense | dithering |
| warmth | friendly | balanced | grain |
| impact | crisp | balanced | mesh |
| ceremonial | sharp | sparse | grain |

Shader follows the routed `font_family` as default; explicit visual direction may override.

## 2. Style Routing (User Keyword → font_family)

Parse the user's brief and route to ONE `font_family`. Every downstream choice follows.

**Keyword → font_family:**

| User keyword (CN + EN) | → font_family · (radius · density · hero_shader) |
|---|---|
| 自然 / 温暖 / 清新 / 教育 / 治愈 / 生活 / 美食 / 亲子 / 萌系 / nature / warm / fresh / cozy / lifestyle / food / kids | → **warmth** (friendly · balanced · grain) |
| 文艺 / 杂志 / 阅读 / 古典 / 编辑 / 印刷 / 出版 / 文化 / editorial / magazine / classic / publishing | → **editorial** (sharp · sparse · grain) |
| 数据中心 / 工程 / 算力 / 监控 / 服务端 / 后端 / fintech / 仪表盘原始 / 工具底层 / data-center / backend / infrastructure / observability | → **technical** (crisp · dense · dithering) |
| SaaS / dashboard / 看板 / 增长 / 后台业务 / b2b / admin / saas / growth | → **geometric** (sharp · balanced · mesh) |
| 运动 / 户外 / 硬核 / 竞技 / 极限 / 速度 / 力量 / 工业 / sport / extreme / outdoor / industrial / heavy | → **impact** (crisp · balanced · mesh) |
| 庆典 / 国潮 / 喜庆 / 仪式 / 婚礼 / 传统 / luxury / 奢华 / festive / ceremonial / wedding / tradition | → **ceremonial** (sharp · sparse · grain) |
| 通用 / 极简 / 严谨 / 商务 / 默认 / minimal / business / corporate / generic / 无信号 | → **geometric** (sharp · balanced · mesh) — **default** |

**Conflict priority:**

1. Explicit families win their own row, leftmost wins on row-1 ties: `impact > ceremonial > editorial > warmth`
2. SaaS / dashboard / 看板 / 增长 / 后台 → **geometric**
3. **technical** only when keywords explicitly contain 数据中心 / 工程 / 算力 / 监控 / 服务端 / 后端 / infrastructure / backend / observability
4. Generic `科技 / tech` alone (no infrastructure modifier) routes to **geometric**
5. No signal → **geometric**

**Verbal color phrases** ("用红色") route through §3 brand color presets, not this table. Family routes from mood/business keywords only. Commit to resolved route; don't ask for clarification on tech keyword variance.

Data label vocabulary stays verbatim — re-skin the visual, never reinterpret metric meaning. **Input record schema is a mock scaffold** — rewrite field labels to match the brief's actual vocabulary; never let scaffold labels like `Q1 目标` / `姓名` / `职位` / `sales rep` / `fldRevenue` surface verbatim in render output. The brief's domain (春节礼盒销售 / fintech 风控 / SaaS 增长 / etc.) supplies the real label set.

## 3. Colors

Color space: OKLCH. **User-anchored expansion**: `brand_color` hex parses to (pL, pC, pH); `--primary` equals the user's color with optional `lightness_shift` offset; chart ramp ramps around the anchor; neutrals share `pH` only. `neutralC` always branded: 0.008 (light) / 0.012 (dark).

### Brand color fidelity (HARD)

`--primary` MUST equal `oklch(primaryL pC pH)` where (pL, pC, pH) is the user's `brand_color` parsed through OKLCH. NEVER fall back to neutral / gray / muted default. If hex parse fails, halt rendering. The user's color is the design's emotional anchor.

### Light mode tokens

OKLCH function MUST use space-separated CSS Color Module Level 4 syntax — `oklch(L C H)` / `oklch(L C H / alpha)`, never comma-separated.

```
brand_color → (pL, pC, pH) in OKLCH; shift = lightness_shift / 100
primaryL     = clamp(pL + shift × 0.15, 0.30, 0.70)
--primary       = oklch(primaryL pC pH)
--primary-hl    = oklch(min(primaryL+0.10, 0.78) pC pH)
--primary-soft  = oklch(0.92 min(pC, 0.04) pH)
--primary-glow  = oklch(primaryL pC pH / 0.15)
--chart-1       = var(--primary)
--chart-2       = oklch(max(primaryL+0.07, 0.40) min(pC, 0.18) pH)
--chart-3       = oklch(max(primaryL-0.12, 0.22) max(min(pC-0.06, 0.14), 0.02) pH)
--chart-4       = oklch(max(primaryL-0.22, 0.18) max(min(pC-0.10, 0.10), 0.02) pH)
--chart-5       = oklch(max(primaryL-0.32, 0.15) max(min(pC-0.14, 0.06), 0.02) pH)
--background / --surface-l1 = oklch(0.985 neutralC pH)
--surface-l2 = oklch(0.965 neutralC pH); --surface-l3 = oklch(0.935 neutralC pH)
--foreground / fg-2 / fg-3 = oklch(0.14|0.42|0.62 0.008 pH)
--divider       = oklch(0.14 0.008 pH / 0.10); --divider-soft = oklch(0.14 0.008 pH / 0.06)
--chart-hover   = oklch(primaryL pC pH / 0.08)   # light
--chart-hover   = oklch(primaryL pC pH / 0.12)   # dark
--quote-bg = oklch(0.965 neutralC pH); --outro-bg = oklch(0.985 neutralC pH)
```

Recharts `<Tooltip cursor={{ fill: 'var(--chart-hover)' }} />` — brand-tinted translucent overlay; lightness equals `primaryL`, only alpha changes between modes.

### Background lightness invariant (HARD)

Light mode `--background` and `--surface-l1` / `--surface-l2` MUST satisfy `L ≥ 0.95`; `--surface-l3` allowed at `L ≥ 0.93` for deeper nested contrast. Dark mode `--background` MUST satisfy `L ≤ 0.16`. `lightness_shift` only modulates `--primary` and chart ramp; NEVER touches bg / surface / foreground / divider / neutrals.

### Dark mode tokens

Same accent algorithm; neutral L flips symmetrically — background 0.10 · surfaces 0.12 / 0.14 / 0.17 · foregrounds 0.92 / 0.70 / 0.50 · divider alpha 0.10 / 0.06. Dark primaryL lifts by +0.10 (clamp 0.42–0.72). `--primary-glow` alpha 0.18 in dark. `--primary-soft` dark = `oklch(0.22 min(pC, 0.04) pH)`. **HARD**: `--primary-soft` is a background-only token — never text color.

### Brand color presets (verbal input)

When users say "用红色" instead of hex: `red #E03131` · `crimson #B83A3A` · `orange #F76707` · `amber #F59F00` · `green #00AC97` · `teal #0EA5E9` · `blue #1E40AF` *(default)* · `indigo #4F46E5` · `purple #7C3AED` · `pink #DB2777` · `slate #64748B` · `black #0F172A`.

### Neutral hue logic

Neutrals (surface / foreground / divider / chart-hover) share `pH` with the accent. Use neutralC chroma (0.008 light / 0.012 dark) — never C=0.

### Foreground role discipline

Body prose rides `--foreground` for full contrast (WCAG 7:1 AAA at 14px+). Meta-labels (eyebrow / colophon / attribution / timestamps, sub-14px) ride `--foreground-2`. Decorative ornaments and disabled states ride `--foreground-3`.

### Color rules

- Focal numbers use `--primary`. Units, percent signs, delta arrows, delta values use `--primary-hl`.
- Charts: single-hue ramp chart-1 → chart-5. Latest period = chart-1; prior periods step to chart-3 → chart-5.
- Depth from Hero shader + chapter rhythm + typographic scale + brand accent. Never shadow stacks. Dividers whisper-thin (≤ 0.12 alpha).
- Cards: filled cards carry NO visible border — fill OR border, never both. Transparent cards may add ONE 1px hairline (`var(--divider)`). One border layer per card; one radius per card. Cards lean on surface fill and spacing for separation.
- Hero is not a chapter — no ChapterStamp inside Hero. Hero ornament: eyebrow + Display Number + delta + lead only.
- Shader-induced contrast issues solve at the shader source — lower `colors[].L` / `colors[].C` directly. Never `backdrop-filter` / mask / opacity overlay on Hero shader (single-layer).
- Brand accent 8–15% of every viewport. Reserved for focal numerals, chart-1 latest, Hero shader breath, chapter index, one structural accent per section.
- No `#000000`. No `#FFFFFF`. Tokens only.

### Chroma constraints (HARD)

| Token family | C ceiling (light) | C ceiling (dark) |
|---|---|---|
| Neutral (surface / foreground / divider) | 0.008 | 0.012 |
| Accent (primary / primary-hl) | 0.22 | 0.22 |
| Chart 1–5 | 0.22 → 0.08 | 0.22 → 0.08 |
| Primary-soft (tag bg) | 0.04 | 0.04 |

Any token with C > ceiling = violation.

### Font fidelity (HARD)

The `font_family`-routed display face is a HARD requirement. Stack order is non-negotiable. If primary face fails, degrade through declared fallback chain — never silently substitute a generic default. Forbidden as rendered: Inter, system-ui, DM Sans (as primary geometric), Arial.

### Weight

| Family | Display weight | Body weight | Ceiling |
|---|---|---|---|
| geometric | 500 | 400 | 500 |
| editorial | 500 | 400 | 500 |
| technical | 500 | 400 | 500 |
| warmth | 400–500 | 400 | 500 |
| impact | 500–600 | 400 | 600 |
| ceremonial | 500 | 400 | 500 |

Restraint is the signature — keep type weight ≤ 500 across all families; `impact` may reach 600 only on Hero Title and Display Number for high-contrast presence. Page-wide weight range ≤ 200 between Display and Body. CJK ceiling 500. **Forbidden Tailwind weight classes:** `font-bold` / `font-extrabold` / `font-black`. Only `impact` Hero/Display may use `font-semibold` (600); other families top at `font-medium` (500).

### Scale

| Level | lg | mobile | Weight |
|---|---|---|---|
| Hero Title | `text-[88px]` | `text-[44px]` | Display |
| Display Number | `text-[140px]` | `text-[64px]` | Display |
| Section Primary | `text-[56px]` | `text-[40px]` | Display |
| Section Secondary | `text-[40px]` | `text-[24px]` | Display |
| Quote | 32px | — | Body |
| Body / Caption | 15 / 13px | — | Body |
| Meta-Label / Eyebrow | 11px | — | Display, `tracking-[0.08em]` / `[0.16em]` |

Display Number: `leading-[0.9]`. Mobile ≈ desktop × 45–50%. Exact breakpoint classes only — no `clamp()`.

Anatomy: focal figure scale `--primary`; unit suffix ~30% figure height, baseline-aligned `gap-2`, `--primary-hl`. Unit never same scale as figure, never above baseline, never wrapped.

OpenType: `font-feature-settings: "kern", "tnum", "lnum"` on all data numbers. `technical` adds `"calt"`.

CJK: primary sans for Hero Title, Chapter Title, Body, Caption; `--number-stack` for Display Number Latin only; `textWrap: "balance"` and `word-break: keep-all` on titles to prevent mid-phrase line break; `max-w-[42ch]` body / `max-w-[18ch]` hero; 0.1em space flanking digits in mixed lines.

Body: `text-[15px]` / 13px caption, body weight, `--foreground` prose. Chapter title: claim-line (5–14 CJK / 4–9 EN), Section Primary, Display weight, `--foreground` — never slogan, never question. Hierarchy: one Primary number per section; tiers differ ≥ 2 steps; emphasis from scale + color, never italic.

### Focal numeric length-based scale step

Long display numbers must downscale: ≤ 7 chars default scale / 8–11 chars drop one tier / ≥ 12 chars drop two tiers. Parent container `min-w-0`; child `whitespace-nowrap`; the section never produces horizontal scroll.

## 5. Spacing & Layout

`density` dial drives spacing rhythm.

| Density | Section py (lg) | Grid gap | Cols |
|---|---|---|---|
| **sparse** | 160–200px | 8–12px | 2–3 |
| **balanced** *(default)* | 96–128px | 24–32px | 3–4 |
| **dense** | 48–72px | 16–24px | 4–6 |

Base unit: 8px. Scale: `1` `2` `3` `4` `6` `8` `12` `16` `24`. Section `px-6` mobile → `px-16` desktop. Container: `max-w-7xl` paragraph-driven; `max-w-5xl` KPI/chart. Grid: `gap-2`, `items-baseline`, `min-w-0`.

Long-scroll cadence: chapters stack vertically, separated by hairline + Marker opener. Content determines height, `min-h-[80vh]` floor. Overflow: truncate, wrap, or scale to longest plausible value.

Density: one observation per viewport. Gaps: `gap-1` tight · `gap-3` label+number · `gap-8` paragraph→KPI · `gap-12` KPI→chart.

KPI row: 4–6 cells, vertical hairline column rule, Display Number + unit + caption each. `px-6 py-4`; first `pl-0`. KPI grid is borderless — no Matrix `border` wrapper, no chart-stage frame. Stack below `md:` with horizontal hairline. Trend `<aside>` carries NO `border-left`.

## 6. Material

`radius` dial drives corner system.

| Token | Value | Vibe |
|---|---|---|
| **sharp** *(default · editorial / geometric / ceremonial)* | 0px | systematic / editorial / minimal |
| **crisp** *(technical / impact)* | 2px | instrumental / fintech |
| **soft** | 6px | saas / dashboard |
| **friendly** *(warmth)* | 12px | consumer / lifestyle / 温暖 |
| **playful** | 16px | 节庆轻盈 / 教育 |

ONE radius per page. Pill/tag radius = sharp 0px always (regardless of dial).

```css
:root { --radius-card: <radius>px; --radius-panel: <radius>px; --radius-pill: 9999px; }
```

Surface: flat ground from `var(--background)` token (no page-level shader). Hero shader is the page's only WebGL layer, scoped to Hero section. Panels lift through hairline + one-step L difference — never shadow stacks, never `backdrop-blur`. Cards lean on surface fill + spacing; edges minimal.

Card chrome: filled card carries NO visible border (use `border-0 shadow-none` on the wrapper). For a hairline-edged card, use a transparent card with ONE 1px `var(--divider)` (≤ 0.12 alpha) — never both fill and border, never nest a bordered wrapper outside a bordered card.

Chapter opener default-style baseline: Badge `CH · NN` (mono, `tracking-[0.16em]`, `border-color: var(--divider)`) → h2 chapter title → full-width hairline divider below. Default style switches between six variants by `font_family` (see §15 ChapterStamp variants); fixed styles keep their pack-specific opener.

Chapter divider: `var(--divider)` 1px, in-chapter rest only.

Panel discipline: `rounded-[var(--radius-card)]` chart frames and card chrome. Each archetype one material logic.

## 7. Motion

Engines: `motion/react` · `motion-plus/react` (AnimateNumber) · `@paper-design/shaders-react` (Hero shader).

```ts
const EASE = {
  out:   [0.16, 0.84, 0.24, 1],
  inOut: [0.7,  0,    0.3,  1],
  snap:  [0.18, 0,    0.05, 1],
  spring:[0.4,  0,    0.3,  1],
}
```

| Category | Duration | Easing |
|---|---|---|
| Hover | 150ms | out |
| Button press | 100ms | snap |
| Element entrance | 500–900ms, y: 32–36px | out |
| Number rolling | 2.0–2.4s | spring, no bounce |
| Curve pathLength | 2.0–2.8s | out |
| WebGL Hero | viewport-paused | speed per shader |

Entrance: Hero uses `animate=` with delays. Section shells, body paragraphs, chart wrappers, prose render visible on first paint without animation wrappers.

Every `whileInView` pairs `viewport={{ once: true, margin: "0px 0px -15% 0px" }}` — no exceptions. Stagger: `staggerChildren: 0.1`. Reduce by 0.02 on mobile.

Motion per viewport: one focal motion only. Hero staged reveal → Time Series area draw → Proportion rail fill → Ranking cascade → Annotation donut → Quote crossfade → Outro signature glow.

Reduced-motion: when `prefers-reduced-motion: reduce` is active, render the final static state directly — no spring, no digit roll, no entrance interpolation. AnimateNumber renders parsed text; `whileInView` skips transition; Hero shader speed drops to 0. CSS fallback `animation-duration: 0.01ms !important`, opacity crossfade only.

### AnimateNumber scope

Wrap every key number: Hero primary, section focal claim, Annotation stat, Ranking top-1, Cluster cell headlines. Don't wrap labels, ordinals, dates, axis values. Cap ≤ 3 per section.

SVG: `pathLength: 0→1` draw-in. No `d` morph. Data null/undefined → render empty state, not broken animation.

## 9. Accessibility & Mobile

WCAG 2.2 AA: ≥4.5:1 text contrast · ≥3:1 UI contrast · 24px tap targets / 44px mobile · focus ring 2px · `prefers-reduced-motion` per §7 · content reflows at 320px · logical heading hierarchy. Body 14px+ rides `--foreground` (WCAG 7:1 AAA); sub-14px metadata rides `--foreground-2`.

Breakpoints (mobile-first): Base < 768px single-column · md ≥ 768px two-column · lg ≥ 1024px full grids · xl ≥ 1440px max-w-5xl gutters absorb.

`min-h-dvh` for full-height. `env(safe-area-inset-bottom)` for sticky elements.

## 10. Do's and Don'ts

Do:
- Neutral ground 60% / brand accent 8–15% / prose rest. ChapterStamp opener on every non-Hero chapter (variant per `font_family` — see §15)
- One structural visual decision per viewport beyond color (scale jump, single stroke, path reveal, crop, or offset)
- Restraint is the signature — when tempted to heavier weight or larger size, prefer scale jump + spacing instead

Don't:
- No heavy shadows / frosted glass / `backdrop-blur` / rim lighting / card-edge glow / text glow
- Use `rounded-xl` / `2xl` / `3xl` / blob / `rounded-full` on cards (pill/tag exception). One radius per page. Add `border-left` / `border-right` > 1px on cards / list items / callouts (absolute ban)
- Render any CTA-shaped affordance — pill/button + bg-primary + label like "查看完整报告" / "Learn more" / "Sign up" / signup forms / email-capture / follow-link. Outro caps with a colophon line + radial glow only. Campaign Report is read-only narrative, not landing page
- Use `background-clip: text` + gradient (gradient text absolute ban). Solid colors only
- Reveal whole sections by opacity fade or repeat identical entrance across sections — vary motion by archetype; sections render visible on first paint and earn motion only on focal moves
- Wrap every number in AnimateNumber — reserve for key claim numbers. Avoid character-by-character text reveals (scramble / typewriter / ticker). Introduce a second hot accent for delta-down
- Animate bar chart bars rising from zero — bars static; reveal highlight only
- Render image background AND WebGL shader on same Hero — mutually exclusive (§15)

## 11. Pattern Overview

Story told in data, not a dashboard. Narrative arc: opening hook → supporting evidence → closing impact. Each section advances one beat. One focal claim + one supporting visual per section. Reader leaves with three things: headline number, the why, the so-what. Archetype names are internal labels — visible eyebrows/captions come from topic, period, data role, business meaning.

### Scope

Scrollable single-page data narrative where numbers are protagonist. Density Low → High (rhythm-controlled); strong archetype alternation; arc Beginning → Middle → End.

Data shapes: time-series · proportions · paired metrics · ranking · grouped metrics · event sequence · peer catalog · annotation.

### Voice

Third-person observational. Statements not CTAs: `Bookings closed at 142,300`. Eyebrows: uppercase mono `tracking-[0.16em]`. Titles: sentence case, no terminal period (`impact` / `technical` allow ALL CAPS Hero title). Body: sentence case full sentences. Numbers: tabular figures, thousands separators, no decimal padding. Period strings: `·` middle dot (U+00B7) + single spaces.

Inline comparison phrase: `从 ¥30.9亿 (2025) 至 ¥36.5亿 (2026) ▲ 18.2%` — one editorial line, baseline-aligned, no `vs` layout.

## 12. Section Archetype Library

A section = archetype (what) + composition treatment (layout) + dominant move (eye-lead).

### Composition Treatments

| Treatment | Logic | Density |
|---|---|---|
| Full-bleed Monolith | One element fills frame, centered | spacious |
| Asymmetric Split | Two unequal columns (3:2 / 2:1) | medium |
| Stacked Band | Full-width bands stacked | medium–dense |
| Matrix Grid | Equal cells N×M, narratively bound, borderless gap-only | dense |
| Proportion Rail | Continuous parts-of-whole rail | medium |
| Offset Frame | Disrupts grid: crop/off-center/overflow | medium |
| Sequence Track | Stepped: index → statement → detail → figure | medium–dense |
| Typographic Field | Type alone, no panels or chrome | spacious–medium |
| Annotation Rail | Main 3/4 (stat + claim) + narrow rail 1/4 (donut + legend) | medium |

Favored: Typographic Field (Hero), Matrix Grid (KPI Cluster), Stacked Band, Asymmetric Split, Annotation Rail.

### Dominant Moves

| Move | Class |
|---|---|
| Scale jump (focal ≥ 2 tiers larger) | steady |
| Single stroke (one line / hairline / Marker) | steady |
| Path reveal (curve draws / rail fills) | steady |
| Crop / bleed | disruptive |
| Offset placement | disruptive |
| Column break | disruptive |

Leads with scale jump and single stroke. Disruptive ≤ 1 chapter per page.

### Archetypes

> Default skeleton stays data-led (numbers are protagonist). Narrative-shape archetypes (Brand Narrative Spine, Testimonial-Threaded) engage ONLY when query explicitly signals brand history / heritage / craftsmanship / founder story OR customer voice / testimonial / case interview.

**Hero Monolith** — Opening anchor. Typographic Field. Shader z 0 absolute inset 0 → content z 2 position relative. No wash overlay (single-layer rule). Mobile: single vertical column. Desktop: title + lead may share left column; focal number block holds visual focus.

**Time Series** — Values over time. Stacked Band *(default)* · Asymmetric Split. Bare recharts `AreaChart`/`LineChart` in `<ResponsiveContainer>`. Trend `<aside>` no `border-left`.

**Proportion Field** — Parts-of-whole. Proportion Rail *(default)* · Stacked Band. Horizontal `BarChart` + `<LabelList>` or shadcn `Progress`. Legend = horizontal hairline divider.

**Ranking / List** — Items by magnitude. Stacked Band (≤ 5) · Matrix Grid (≥ 6). Scale jump on top-1. List typography — never recharts `BarChart` for ranking.

**Grouped Metric Cluster** — Parallel metrics, one claim. Matrix Grid 2×2/2×3: CSS `grid gap-1`, NO wrapper border, NO chart-stage frame. Each cell `bg-surface-l2 rounded-[var(--radius-card)] p-6 md:p-8`.

**Sequence / Timeline** — Time-ordered events. Sequence Track default. Horizontal (desktop): 3–5 col grid, primary-bordered dots, node line through dot center. Mobile fallback: vertical timeline, left-aligned, 1px hairline rail.

**Peer Set / Catalog** — Same-kind peers. Matrix Grid default. Shadcn `Card` (border-0 shadow-none p-0).

**Quote Interstitial** — Narrative pause. Typographic Field. Unadorned, opening en-dash `—` `--primary` lead-in. ≤ 28 words `max-w-[72ch]`, body weight `--foreground` — no italic, no `border-left`.

**Annotation Rail** — Stat + claim (3/4) + donut + legend (1/4). Donut: `<PieChart><Pie innerRadius={48} outerRadius={80} paddingAngle={2}>` with `Cell fill={var(--chart-N)}`. Donut is glyph, not focus.

**Outro Reverent** — End. Typographic Field. Closing claim Section Primary + radial spotlight `var(--primary-glow)` ellipse 60% 50% at 50% 75% → transparent 70%, `z-index: -1`. Alpha 0.15 light / 0.18 dark. **Outro material discipline — HARD GATE.** Typographic Field treatment ONLY. NO `backgroundColor`, NO `borderRadius`, NO rounded surface panel chrome on the outer section. The radial `--primary-glow` `::before` is the only decorative layer.

**Brand Narrative Spine** — Narrative-led, data as supporting evidence. Engages on brand-history / heritage / craftsmanship / founder-story triggers. Structure: opening anecdote → period of origin → craftsmanship detail → present-moment data inlay → future intent. Long-form prose dominates page volume; figures blend into sentences rather than standalone display blocks; AnimateNumber reserved for focal claim only. Anti-refs: never render as KPI Cluster grid / chart-as-hero / grid-of-cards.

**Testimonial-Threaded** — Customer voice interleaved with data points. Engages on customer-voice / testimonial / case-interview triggers. Alternating Stacked Band where each band pairs a brief quote with one inline data sentence the quote substantiates. Quote and supporting data MUST sit within the same band, voice-then-evidence rhythm. Never render quotes as parallel columns / card-of-quote with shadow / border / rounded-card chrome.

## 13. Composition

> Default composition skeleton assumes data-led narrative. When Brand Narrative Spine OR Testimonial-Threaded archetype trigger matches the user query, that archetype's recipe overrides the default skeleton.

Default: Hero → KPI Cluster → Time Series → Timeline → Key Insights → Ranking → Proportion → Annotation Rail → Quote → Outro. Section count follows data; stop before filler.

### Rhythm

1. **Density rotation** — adjacent differ (dense / medium / spacious); no two consecutive dense.
2. **Treatment variety** — no two consecutive same treatment or archetype.
3. **Bold-move budget** — disruptive ≤ ceil(N × 0.25).
4. **Break cadence** — ≥ 1 section uses Full-bleed, Offset, or Typographic Field. Hero + Outro satisfy.

### Rules

Ground consistent across chapters; vary rhythm through density, hairlines, accent position. Chapter markers `01` `02` … `08`. ChapterStamp opener on every non-Hero chapter (one per chapter, no exceptions; variant rendered per `font_family` per §15). Chapter divider for in-chapter rests, sparingly.

### Charts tooltip & cursor (HARD)

Wire every Recharts `<Tooltip>` with `content={<ChartTooltipCard />}` (see §17) — never let Recharts default render (default emits black prose unreadable in dark mode). BarChart cursor `<Tooltip cursor={{ fill: 'var(--chart-hover)' }} />`. AreaChart / LineChart cursor: dashed `var(--primary)` stroke 0.5 opacity on transparent fill. PieChart no cursor.

## 17. Components Inventory

### Hero shader (per `hero_shader` dial)

Pass hex/rgb/hsl strings to paper-shaders `colors` and `colorBack` props — the shader engine does not parse CSS `oklch()`. CSS tokens with oklch() still apply on regular DOM elements.

| Engine | Props schema | colors sampling | Numeric range |
|---|---|---|---|
| **mesh** (`MeshGradient`) | `colors[5]` · `distortion` · `swirl` · `grainMixer` · `speed` | Light: 5 hex L 0.925–0.975 C 0.008–0.040 + 1 neighbor (pH+22). Dark: 5 hex L 0.115–0.480 C 0.012–0.075. Brand peak Light L 0.925 / Dark L 0.48. | distortion 0.80 · swirl 0.30 · grainMixer 0.06 (light) / 0.10 (dark) · speed 0.85 |
| **grain** (`GrainGradient`) | `shape='wave'` · `colors[4]` · `colorBack` · `softness` · `intensity` · `noise` · `scale` · `rotation` · `offsetX/Y` · `fit` · `speed` | Light: 4 hex L 0.925–0.975 C 0.008–0.040; colorBack L 0.975 C 0.006. Dark: 4 hex L 0.115–0.480 C 0.012–0.065; colorBack L 0.125 C 0.010. | softness 0.9 · intensity 0.65 (light) / 0.45 (dark) · noise 0.08 (light) / 0.04 (dark) · scale 1.8 · offsetY 0.24 · speed 1.72 (Light mode requires higher intensity + noise so grain is perceptible against L 0.975 backdrop) |
| **dithering** (`Dithering`) | `type='8x8'` · `shape='simplex'` · `size` · `scale` · `colorFront` · `colorBack` · `speed` | Light: colorFront L 0.925 C 0.018; colorBack L 0.965 C 0.006. Dark: colorFront L 0.420 C 0.040; colorBack L 0.155 C 0.010. | size 4 · scale 1.4 · speed 0.70 |
| **none** | n/a | static CSS dot-grid or line-grid fallback | n/a |

Sampling: each numeric param sampled within row's range, 1 decimal. Brand hue `pH` from `brand_color`. Neighbor accent at `(pH + 22) % 360`. **colors[] L invariant — HARD GATE.** EVERY entry of mesh `colors[5]` / grain `colors[4]` (and dithering `colorFront` / `colorBack`) MUST satisfy `L ∈ [0.925, 0.975]` in light / `L ∈ [0.115, 0.480]` in dark. The raw `brand_color` L is never passed through — project onto the engine's L band first. Policy: 1 WebGL instance per page (Hero only); CSS fallback `backgroundColor=var(--background)`; foreground image OK iff user-provided; NO wash overlay; scope Hero ONLY.

Shader selection per archetype: `mesh` for geometric / impact (modern SaaS / dynamic tech / bold composition); `grain` for editorial / ceremonial / warmth (paper texture / ceremonial calm / warm cozy); `dithering` for technical (instrumental / fintech). Wrap each WebGL host in `{position:'absolute', inset:0, width:'100%', height:'100%', zIndex:0}`; project user `brand_color` to the engine's L band before sampling each swatch.

### AnimateNumber

`motion-plus/react` AnimateNumber. Children pure numeric only. Use `parseDisplayValue()` to split formatted values (prefix / pure number / suffix). Wrap in `inline-flex items-baseline gap-1 whitespace-nowrap`. Cap ≤ 3 per section. Reduced-motion: render parsed static text instead.

```tsx
import { AnimateNumber } from "motion-plus/react";

function parseDisplayValue(value: string | number | undefined) {
  if (value === undefined || value === null) return { prefix: "", number: "0", suffix: "" };
  const str = String(value);
  const match = str.match(/^([^\d\-]*?)(-?[\d,]+\.?\d*)(.*)$/);
  if (!match) return { prefix: "", number: "0", suffix: "" };
  return {
    prefix: (match[1] ?? "").trim(),
    number: match[2].replace(/,/g, ""),
    suffix: (match[3] ?? "").trim(),
  };
}

const { prefix, number, suffix } = parseDisplayValue(displayValue);
<span className="inline-flex items-baseline gap-1 whitespace-nowrap">
  {prefix && <span style={{ color: "var(--primary-hl)" }}>{prefix}</span>}
  <AnimateNumber
    style={{ color: "var(--primary)" }}
    transition={{ type: "spring", duration: 2.2, bounce: 0 }}
  >
    {number || 0}
  </AnimateNumber>
  {suffix && <span style={{ color: "var(--primary-hl)" }}>{suffix}</span>}
</span>
```

### ChartTooltipCard

Custom tooltip card wired to every Recharts `<Tooltip content={...} />`. **Template inline strict — 4 props all required:** `borderRadius: 12` + `boxShadow: '0 4px 16px rgba(0,0,0,0.06)'` + `minWidth: 140` + `background: 'var(--surface-l2)'`;omitting any one = tooltip looks unfinished. `px-4 py-3` padding, no border. Top: period label `text-[10px] uppercase` `tracking-[0.16em]` `--foreground-3` mono, `mb-2`. Each row: `flex items-center gap-2` — primary-filled dot (`size-2 rounded-full`) + value `text-[15px] font-medium` `--foreground` + unit `text-[12px] font-normal` `--foreground-3`. Color tokens guarantee dark-mode readability.

```tsx
function ChartTooltipCard({ active, payload, label, periodSuffix = "", unitSuffix = "" }: any) {
  if (!active || !payload?.length) return null;
  return (
    <div className="px-4 py-3" style={{ background: "var(--surface-l2)", borderRadius: 12, boxShadow: "0 4px 16px rgba(0,0,0,0.06)", minWidth: 140 }}>
      <div className="text-[10px] uppercase mb-2" style={{ fontFamily: "var(--mono-stack)", letterSpacing: "0.16em", color: "var(--foreground-3)" }}>{label} {periodSuffix}</div>
      {payload.map((entry: any, i: number) => (
        <div key={entry.dataKey ?? i} className="flex items-center gap-2">
          <span className="block size-2 rounded-full" style={{ background: "var(--primary)" }} aria-hidden />
          <span className="text-[15px] font-medium" style={{ color: "var(--foreground)" }}>{entry.value}</span>
          <span className="text-[12px] font-normal" style={{ color: "var(--foreground-3)" }}>{unitSuffix}</span>
        </div>
      ))}
    </div>
  );
}

```
