## 1. Brand & Style

Mood: depends on `font_family`. Default vibe: **Restrained · Precise · Single-hue · Flat**.

Proposition: a parameterized campaign-report base. Dial values arrive via URL query (`?style=default&mode=...&color=...&lightness=...&font=...`); advanced dials (`hero=`, `radius=`, `density=`) auto-derive from STYLE_PRESETS[font_family] when not specified. Defaults: `mode=light` · `color=#1E40AF` · `lightness=0` · `font=geometric`. `accent_strategy` removed — always mono/bordered. `neutral_temperature` removed — internal neutralC always branded. `card_border` fixed bordered.

Style presets (font_family → advanced dials):

## 2. Style Routing (User Keyword → font_family)

> ⚠️ **READ FIRST.** Before sampling tokens or assembling sections, parse the user's brief and route to ONE `font_family`. Every downstream choice (radius, density, hero_shader, font stacks, weight ceiling) follows.

**Keyword → font_family:**

| User keyword (CN + EN) | → font_family · (radius · density · hero_shader) |
|---|---|
| 自然 / 温暖 / 清新 / 教育 / 治愈 / 生活 / 美食 / 亲子 / 萌系 / nature / warm / fresh / cozy / lifestyle / food / kids | → **warmth** (friendly · balanced · grain) |
| 文艺 / 杂志 / 阅读 / 古典 / 编辑 / 印刷 / 出版 / 文化 / editorial / magazine / classic / publishing | → **editorial** (sharp · sparse · mesh) |
| 科技 / SaaS / 数据 / fintech / 仪表盘 / 工具 / 后台 / 系统 / tech / data / dashboard / admin / tools / b2b | → **technical** (crisp · dense · dithering) |
| 运动 / 户外 / 硬核 / 竞技 / 极限 / 速度 / 力量 / 工业 / sport / extreme / outdoor / industrial / heavy | → **impact** (crisp · balanced · mesh) |
| 庆典 / 国潮 / 喜庆 / 仪式 / 婚礼 / 传统 / luxury / 奢华 / festive / ceremonial / wedding / tradition | → **ceremonial** (sharp · sparse · mesh) |
| 通用 / 极简 / 严谨 / 商务 / 默认 / minimal / business / corporate / generic / 无信号 | → **geometric** (sharp · balanced · mesh) — **default** |

**Conflict priority** (when keywords mix families): `impact > ceremonial > technical > editorial > warmth > geometric` — leftmost wins.

**No signal → geometric.** Don't ask for clarification; commit to the default.

**Verbal color phrases route through §3 brand color presets, not through this table.** "用红色" routes to `brand_color=#E03131`, not to a family. Family routes from mood/business keywords only.

## 3. Colors

Color space: OKLCH. **User-anchored expansion**: `brand_color` hex parses to (pL, pC, pH); `--primary` equals the user's color with optional `lightness_shift` offset; chart ramp ramps around the anchor; neutrals share `pH` only (their L/C follow the standardized ramp). `neutralC` always branded: 0.008 (light) / 0.012 (dark) — no user-facing dial.

### Light mode tokens (algorithm)

```
(pL, pC, pH) = hexToOKLCH(brand_color)
shift        = lightness_shift / 100
primaryL     = clamp(pL + shift × 0.15, 0.30, 0.70)

--primary       = oklch(primaryL,                  pC,            pH)
--primary-hl    = oklch(min(primaryL+0.10, 0.78),  pC,            pH)
--primary-soft  = oklch(0.92,                      min(pC, 0.04), pH)
--primary-glow  = oklch(primaryL,                  pC,            pH, 0.15)
--chart-1       = var(--primary)
--chart-2       = oklch(primaryL + 0.07,           pC - 0.02,     pH)
--chart-3       = oklch(primaryL - 0.03,           pC - 0.06,     pH)
--chart-4       = oklch(primaryL - 0.13,           pC - 0.10,     pH)
--chart-5       = oklch(primaryL - 0.23,           pC - 0.14,     pH)
--background    = oklch(0.985, neutralC, pH)
--surface-l1    = oklch(0.985, neutralC, pH)
--surface-l2    = oklch(0.965, neutralC, pH)
--surface-l3    = oklch(0.935, neutralC, pH)
--foreground    = oklch(0.14,  0.008,    pH)
--foreground-2  = oklch(0.42,  0.008,    pH)
--foreground-3  = oklch(0.62,  0.008,    pH)
--border        = oklch(0.14,  0.008,    pH, 0.10)
--border-strong = oklch(0.14,  0.008,    pH, 0.22)
--chart-hover   = oklch(0.14,  0.008,    pH, 0.05)
--quote-bg      = oklch(0.965, neutralC, pH)
--outro-bg      = oklch(0.985, neutralC, pH)
```

### Dark mode tokens

Same accent algorithm; neutral L flips symmetrically — background 0.10 · surfaces 0.12 / 0.14 / 0.17 · foregrounds 0.92 / 0.70 / 0.50 · border alpha 0.14 / 0.28. Dark primaryL lifts by +0.10 (clamp 0.42–0.72) to maintain ≥ 4.5:1 contrast. `--primary-glow` alpha 0.18 in dark.

### Brand color presets (verbal input)

When users say "用红色" instead of hex: `red #E03131` · `crimson #B83A3A` · `orange #F76707` · `amber #F59F00` · `green #00AC97` · `teal #0EA5E9` · `blue #1E40AF` *(default)* · `indigo #4F46E5` · `purple #7C3AED` · `pink #DB2777` · `slate #64748B` · `black #0F172A`. Priority: `?color=` > `?named=` > default.

### Neutral hue logic

Neutrals (surface / foreground / border / chart-hover) share `pH` with the accent — OKLCH L is perceptually uniform across hues. Warm-hue surface (pH ≈ 30) reads warm gray; cool-hue surface (pH ≈ 232) reads cool gray. Pure C=0 grays look clinical; branded chroma keeps emotional cohesion.

### Color rules

- Focal numbers use `--primary`. Units, percent signs, delta arrows, delta values use `--primary-hl` (lighter L +0.10, same hue/chroma).
- Charts: single-hue ramp chart-1 → chart-5. Latest period = chart-1 brand accent; prior periods step to chart-3 → chart-5. Hover/active uses `--chart-hover`.
- Depth from Hero shader + chapter rhythm + typographic scale + brand accent — never shadow stacks. Borders whisper-thin (≤ 0.10 alpha); surfaces stack ≤ one L step.
- Card border rule (R-113.2): filled cards (e.g. `bg-surface-l2`, `bg-card`) carry NO visible border — fill OR border, never both. Transparent / non-filled cards may add ONE 1px hairline (`var(--border)` ≤ 22% alpha). NEVER nest a bordered wrapper inside another bordered card — ONE border layer per card, ONE radius per card. Heavy / dark borders are dividers only (chapter hairline / `<hr>`) — never card edges.
- Hero is not a chapter — no ChapterStamp / chapter numeral / kicker inside Hero. Hero ornament: eyebrow + Display Number + delta + lead only.
- Shader-induced contrast issues solve at the shader source — lower `colorFront` lightness/chroma directly. Never `backdrop-filter` / mask / opacity overlay on Hero shader (single-layer architecture).
- Brand accent 8–15% of every viewport. Reserved for focal numerals, chart-1 latest, Hero shader breath, chapter index, one structural accent per section.
- No `#000000`. No `#FFFFFF`. Tokens only.

### Chroma constraints (HARD)

| Token family | C ceiling (light) | C ceiling (dark) |
|---|---|---|
| Neutral (surface / foreground / border) | 0.008 | 0.012 |
| Accent (primary / primary-hl) | 0.22 | 0.22 |
| Chart 1–5 | 0.22 → 0.08 | 0.22 → 0.08 |
| Primary-soft (tag bg) | 0.04 | 0.04 |

Any token with C > ceiling = violation. Regenerate.

## 4. Typography

`font_family` dial drives **4 CSS vars**: `--title-stack` (标题 / 中英混排) · `--number-stack` (KPI / Display 数字) · `--body-stack` (正文 / Lead / Caption) · `--mono-stack` (eyebrow / meta / colophon). `--display-stack` and `--sans-stack` retained as aliases for the 6 fixed styles. Number elements use `font-feature-settings: "tnum"` on `--number-stack`.

### Font stacks (4 roles)

| Family | `--title-stack` | `--number-stack` | `--body-stack` | `--mono-stack` |
|--------|-----------------|------------------|----------------|----------------|
| **geometric** | Geist · Noto Sans SC · PingFang SC | Geist · Noto Sans SC | Noto Sans SC · PingFang SC | Geist Mono · JetBrains Mono |
| **editorial** | Spectral · EB Garamond · Noto Serif SC · Songti SC | Spectral · EB Garamond | Noto Serif SC · Source Han Serif SC | IBM Plex Mono |

| **warmth** | Nunito · LXGW WenKai TC · Comfortaa · 霞鹜文楷 | Nunito · Comfortaa | Nunito · Noto Sans SC · PingFang SC | DM Mono · JetBrains Mono |
| **impact** | Bebas Neue · Anton · Smiley Sans · 得意黑 · Noto Sans SC | Bebas Neue · Anton | Noto Sans SC · PingFang SC | JetBrains Mono |
| **ceremonial** | Playfair Display · Ma Shan Zheng · Cinzel · 马善政毛笔楷书 | Playfair Display · Cinzel | Zhuque Fangsong · 朱雀仿宋 · Noto Serif SC | IBM Plex Mono |

### Mandatory binding

```css
:root {
  --title-stack:  <stack from dial>;
  --number-stack: <stack from dial>;
  --body-stack:   <stack from dial>;
  --mono-stack:   <stack from dial>;
}
body { font-family: var(--body-stack); }
h1, h2, h3, .rep-hero-title, .rep-chapter-title { font-family: var(--title-stack); }
.rep-hero-num, .rep-kpi-num, [data-num] { font-family: var(--number-stack); font-feature-settings: "tnum", "lnum"; }
.rep-eyebrow, .rep-colophon, [data-meta] { font-family: var(--mono-stack); }
```

Forbidden as rendered: Inter, system-ui, DM Sans (as primary geometric), Arial. `editorial` → serifs must be visible (Spectral / EB Garamond). `warmth` → Nunito / Comfortaa rounded forms must be visible; CJK uses LXGW WenKai TC for title only — NEVER body. `impact` → CJK heavy/condensed shape visible. `ceremonial` → 装饰字体 (Ma Shan Zheng / Playfair) used in `--title-stack` only; body uses readable Zhuque Fangsong / Noto Serif SC —装饰字体 NEVER on body.

### Scale

| Level | lg | mobile | Weight |
|-------|----|--------|--------|
| Page Title | `text-[120px]` | `text-[56px]` | Display weight |
| Display Number | `text-[200px]` | `text-[96px]` | Display weight |
| Section Primary | `text-[80px]` | — | Display weight |
| Section Secondary | `text-[48px]` | — | Display weight |
| Section Tertiary | `text-[28px]` | — | Body weight |
| Quote | `text-[36px]` | — | Body weight |
| Body | `text-[15px]` | — | Body weight |
| Caption | `text-[13px]` | — | Body weight |
| Meta/Label | `text-[11px]` | — | Display weight, `tracking-[0.08em]` |
| Eyebrow | `text-[11px]` | — | Display weight, `tracking-[0.16em]` |

Display Number: `leading-[0.86]` `tracking-[-0.04em]`. Exact breakpoint classes — no `clamp()` (sub-pixel jitter degrades AnimateNumber spring).

Display Number anatomy: focal figure scale `--primary`; unit suffix ~28–30% figure height, baseline-aligned `gap-2`, `--primary-hl`. Never same scale as figure, never above baseline, never wrapped.

OpenType: `font-feature-settings: "kern", "tnum", "lnum"` on all data numbers. `technical` adds `"calt"`.

CJK: primary sans for Hero Title, Chapter Title, Body, Caption; `--number-stack` for Display Number Latin only; `textWrap: "balance"`; `max-w-[42ch]` body / `max-w-[18ch]` hero; 0.1em space flanking digits in mixed lines.

Body: `text-[15px]` / `text-[13px]` caption, body weight, `--foreground-2` prose, `--foreground-3` only decorative.

Chapter title: claim-line (5–14 CJK / 4–9 EN words), Section Primary, Display weight, `--foreground`. Names the outcome — never slogan, never ALL-CAPS (except `impact` and `technical`), never question.

Hierarchy: one Primary number per section. Tiers differ ≥ 2 steps. Emphasis from scale + color — never italic, never bold above weight ceiling.

### Focal numeric length-based scale step

Apply length-based conditional className on Display Number from `displayNumber.length`: ≤ 7 char → default scale / 8–11 char → drop one tier / ≥ 12 char → drop two tiers. Parent `min-w-0` AND child `whitespace-nowrap`. Don't rely on `min-w-0` alone or `clamp()`.

`density` dial drives spacing rhythm.

| Density | Section py (lg) | Grid gap | Cols |
|---|---|---|---|
| **sparse** | 160–200px | 8–12px | 2–3 |
| **balanced** *(default)* | 96–128px | 24–32px | 3–4 |
| **dense** | 48–72px | 16–24px | 4–6 |

Base unit: 8px. Scale: `1` `2` `3` `4` `6` `8` `12` `16` `24`. Section `px-6` mobile → `px-16` desktop. Container: `max-w-7xl` paragraph-driven; `max-w-5xl` KPI/chart. Grid: `gap-2`, `items-baseline`, `min-w-0`.

Long-scroll cadence: chapters stack vertically, separated by hairline + Marker opener. Content determines height, `min-h-[80vh]` floor. Overflow: truncate, wrap, or scale to longest plausible value.

Density: one observation per viewport. Gaps: `gap-1` tight · `gap-3` label+number · `gap-8` paragraph→KPI · `gap-12` KPI→chart.

KPI row: 4–6 cells, vertical hairline column rule, Display Number + unit + caption each. `px-6 py-4`; first `pl-0`. KPI grid is borderless — no Matrix `border` wrapper, no chart-stage frame. Stack below `md:` with horizontal hairline. Trend `<aside>` carries NO `border-left` (absolute ban; side-stripe).

## 6. Material

`radius` dial drives corner system.

| Token | Value | Vibe |
|---|---|---|
| **sharp** *(default · editorial / geometric / ceremonial)* | 0px | systematic / editorial / minimal |
| **crisp** *(technical / impact)* | 2px | instrumental / fintech |
| **soft** | 6px | saas / dashboard |
| **friendly** *(warmth)* | 12px | consumer / lifestyle / 温暖 |
| **playful** | 16px | 节庆轻盈 / 教育 |

ONE radius per page. Pill/tag radius = sharp 0px always (regardless of dial) — pills stay sharp for chart legends and data labels even when card radius is friendly/playful.

```css
:root { --radius-card: <radius>px; --radius-panel: <radius>px; --radius-pill: 9999px; }
```

Surface: flat ground from `var(--background)` token (no page-level shader). Hero shader is the page's only WebGL layer, scoped to Hero section. Panels lift through hairline + one-step L difference — never shadow stacks, never `backdrop-blur`.

Borders: Whisper `1px solid var(--border)` · Strong `var(--border-strong)`. Shadow: none on cards.

Card chrome: filled `<Card>` (`bg-surface-l2` / `bg-card`) carries NO visible border — `<Card className="border-0 shadow-none"><div className="p-5 md:p-6">…</div></Card>`. If a hairline edge is needed, use a transparent card with ONE 1px border (`var(--border)`); never both fill and border, never nest a bordered wrapper outside a bordered card. Double-Bezel (outer ring + inner card) is fixed-style-only, not a default pattern.

Chapter opener (Marker · hairline-banner pattern): Badge `CH · NN` (mono, `tracking-[0.16em]`, `border-color: var(--border-strong)`) → h2 chapter title → shadcn `<Separator />` full-width below. Numeral and title typography per `font_family` dial. No SVG stamp / solid-fill / banner kicker — those belong to fixed styles only.

Chapter divider: `oklch(1 0 0 / 0.08) h-px` (light) / `oklch(0 0 0 / 0.12) h-px` (dark). In-chapter rest only.

Panel discipline: `rounded-[var(--radius-card)]` chart frames and card chrome. Each archetype one material logic.

## 7. Motion

Engines: `motion/react` · `motion-plus/react` (AnimateNumber) · `@paper-design/shaders-react` (Hero shader, per `hero_shader` dial).

```ts
const EASE = {
  out:   [0.16, 0.84, 0.24, 1],
  inOut: [0.7,  0,    0.3,  1],
  snap:  [0.18, 0,    0.05, 1],
  spring:[0.4,  0,    0.3,  1],
}
```

| Category | Duration | Easing |
|---|---|---|
| Hover | 150ms | out |
| Button press | 100ms | snap |
| Element entrance | 500–900ms, y: 32–36px | out |
| Number rolling | 1.2–2.0s | spring, no bounce |
| Curve pathLength | 2.0–2.8s | out |
| WebGL Hero | viewport-paused | speed per shader |

Entrance: Hero uses `animate=` with delays. Section shells, body paragraphs, chart wrappers, prose render visible on first paint without animation wrappers.

Every `whileInView` must pair `viewport={{ once: true, margin: "0px 0px -15% 0px" }}` — no exceptions. Without `once: true`, elements reset to initial (opacity 0 / scaleX 0) on scroll-out and disappear.

Stagger: `staggerChildren: 0.1` from `"first"`. Reduce by 0.02 on mobile.

Motion per viewport: one focal motion only. Hero staged reveal → Time Series area draw → Proportion rail fill → Ranking cascade → Annotation donut → Quote crossfade → Outro signature glow. Vary by archetype.

### AnimateNumber scope

Wrap every key number: Hero primary, section focal claim, Annotation stat, Ranking top-1, Cluster cell headlines. Do not wrap labels, ordinals, dates, axis values. Cap ≤ 3 per section. `AnimateNumber` accepts pure numeric strings only — use `parseDisplayValue()` to split Bitable formatted values:

```ts
// parseDisplayValue("¥1,234,567") → { prefix: '¥', number: '1234567', suffix: '' }
function parseDisplayValue(raw: string): { prefix: string; number: string; suffix: string } { /* … */ }
```

SVG: `pathLength: 0→1` draw-in. No `d` morph.

`prefers-reduced-motion`: `animation-duration: 0.01ms !important`; opacity crossfade only; WebGL `speed: 0`; AnimateNumber plain text.

Data-driven invariant: null/undefined → render empty state, not broken animation.

## 9. Accessibility & Mobile

WCAG 2.2 AA: ≥4.5:1 text contrast · ≥3:1 UI contrast · `size-6` (24×24px) targets, `size-11` (44×44px) mobile · `ring-2` focus ring · `prefers-reduced-motion` dual-layer · content reflows at 320px · logical heading hierarchy.

## 10. Do's and Don'ts

Do:
- Neutral ground 60% / brand accent 8–15% / prose rest. Marker · hairline-banner opener on every non-Hero chapter.
- Focal numerals `--primary`; units/percent/delta `--primary-hl` inline baseline. Hero leads with Display Number + paragraph subtitle.
- Single-hue chart ramp chart-1 → chart-5. Latest period = brand accent; older steps to chart-3 → chart-5.
- One structural visual decision per viewport beyond color.
- Hero shader single-layer: contrast adjustments at shader `colors[].L` / `colors[].C` — never wash overlay.

Don't:
- Render focal numerals in `--foreground` — digits `--primary`; prose holds foreground.
- Use accent palettes outside `pH`. No heavy shadows / frosted glass / `backdrop-blur` / rim lighting / card-edge glow / text glow.
- Use `rounded-xl` / `2xl` / `3xl` / blob / `rounded-full` on cards (pill/tag exception). One radius per page.
- Add `border-left` / `border-right` > 1px on cards / list items / callouts / `<aside>` (absolute ban; side-stripe).
- Stack two borders on the same card (outer wrapper + inner card both bordered). One border layer per card, one radius per card. No Double-Bezel in default style.
- Render any CTA-shaped affordance — no `<Button>` for "Learn more / Sign up / Get started / View demo / Read more", no signup forms, no email-capture, no follow-link tile. Campaign Report is a read-only narrative artifact, not a marketing landing page. Buttons are reserved for chart legend toggles and data filters.
- Use `background-clip: text` + gradient (absolute ban; gradient text). Solid colors only.
- Nest panels > 1 level or wrap sections in page-level containers.
- Use Inter / Roboto / Space Grotesk / Plus Jakarta (unless `warmth`) or overused faces outside declared stacks.
- Apply weight above family ceiling. Body / Lead 400–500 (warmth allows 500 ceiling).
- Use 装饰字体 (Ma Shan Zheng / Playfair / Comfortaa) as `--body-stack` — title-stack only.
- Repeat same panel material every chapter. Vary by archetype.
- Fade whole sections opacity-only, repeat identical `y + opacity` reveals, or animate CSS layout. Animate `transform` and `opacity`.
- Tween numbers as single value or duplicate unit/percent; per-digit spring only.
- Use ease strings; cubic-bezier arrays only. Use `min-h-dvh` not `h-screen`.
- Render text below `text-[10px]`; required reading `text-[14px]+`.
- Wrap every number in AnimateNumber — reserve for key claim numbers.
- Use `whileInView` without `viewport={{ once: true, margin: "0px 0px -15% 0px" }}`.
- Use `useScroll` / `useTransform` / `scrollYProgress` for Hero exit or scroll-linked parallax.
- Use ScrambleText / Typewriter / Ticker / character-level reveal.
- Introduce a second hot accent for delta-down or error. Neutral foreground carries those.
- Animate bar chart bars rising from zero — bars render static; highlighted bar uses `clip-path` reveal once.
- Wrap chapter `<section>` / chart wrappers / KPI grids / body paragraphs in `motion.div` with `initial={{opacity:0}}` + `whileInView`. Render visible on first paint.
- Stack `.rep-hero-shader-wash` linear-gradient mask on Hero shader (single-layer rule).

## 11. Pattern Overview

Story told in data, not a dashboard. Narrative arc: opening hook → supporting evidence → closing impact. Each section advances one beat. One focal claim + one supporting visual per section. Reader leaves with three things: headline number, the why, the so-what. Archetype names are internal labels — visible eyebrows/captions come from topic, period, data role, business meaning.

### Scope

Scrollable single-page data narrative where numbers are protagonist. Density Low → High (rhythm-controlled); strong archetype alternation; arc Beginning → Middle → End.

Data shapes: time-series · proportions · paired metrics · ranking · grouped metrics · event sequence · peer catalog · annotation.

### Voice

Third-person observational. `we` only in attribution. Statements not CTAs: `Bookings closed at 142,300`. Eyebrows: uppercase mono `tracking-[0.16em]`. Titles: sentence case, no terminal period (`impact` / `technical` allow ALL CAPS Hero title). Body: sentence case full sentences. Numbers: tabular figures, thousands separators, no decimal padding. Period strings: `·` middle dot (U+00B7) + single spaces.

Inline comparison phrase: `从 ¥30.9亿 (2025) 至 ¥36.5亿 (2026) ▲ 18.2%` — one editorial line, baseline-aligned, no `vs` layout.

## 12. Section Archetype Library

A section = archetype (what) + composition treatment (layout) + dominant move (eye-lead).

### Composition Treatments

| Treatment | Logic | Density |
|---|---|---|
| Full-bleed Monolith | One element fills frame, centered | spacious |
| Asymmetric Split | Two unequal columns (3:2 / 2:1) | medium |
| Stacked Band | Full-width bands stacked | medium–dense |
| Matrix Grid | Equal cells N×M, narratively bound, borderless gap-only | dense |
| Proportion Rail | Continuous parts-of-whole rail | medium |
| Offset Frame | Disrupts grid: crop/off-center/overflow | medium |
| Sequence Track | Stepped: index → statement → detail → figure | medium–dense |
| Typographic Field | Type alone, no panels or chrome | spacious–medium |
| Annotation Rail | Main 3/4 (stat + claim) + narrow rail 1/4 (donut + legend) | medium |

Favored: Typographic Field (Hero), Matrix Grid (KPI Cluster), Stacked Band, Asymmetric Split, Annotation Rail.

### Dominant Moves

| Move | Class |
|---|---|
| Scale jump (focal ≥ 2 tiers larger) | steady |
| Single stroke (one line / hairline / Marker) | steady |
| Path reveal (curve draws / rail fills) | steady |
| Crop / bleed | disruptive |
| Offset placement | disruptive |
| Column break | disruptive |

Leads with scale jump and single stroke. Disruptive ≤ 1 chapter per page.

### Archetypes

**Hero Monolith** — Opening anchor. Typographic Field. Shader z 0 absolute inset 0 → content z 2 position relative. No wash overlay (single-layer rule).

**Sequence / Timeline** — Time-ordered events. Sequence Track default. Horizontal (desktop): 3–5 col grid, primary-bordered dots, node line through dot center (margin-math). Shadcn `<Separator />` between nodes. Mobile fallback: vertical timeline, left-aligned, 1px `--border-strong` rail.

**Peer Set / Catalog** — Same-kind peers. Matrix Grid default. Shadcn `Card` (border-0 shadow-none p-0).

**Quote Interstitial** — Narrative pause. Typographic Field. Unadorned, opening en-dash `—` `--primary` lead-in. ≤ 28 words `max-w-[72ch]`, body weight — no italic, no `border-left`.

## 13. Composition

Default: Hero → KPI Cluster → Time Series → Timeline → Key Insights → Ranking → Proportion → Annotation Rail → Quote → Outro. Section count follows data; stop before filler.

### Rhythm

1. **Density rotation** — adjacent differ (dense / medium / spacious); no two consecutive dense.
2. **Treatment variety** — no two consecutive same treatment or archetype.
3. **Bold-move budget** — disruptive ≤ ceil(N × 0.25).
4. **Break cadence** — ≥ 1 section uses Full-bleed, Offset, or Typographic Field. Hero + Outro satisfy.

### Rules

Ground consistent across chapters; vary rhythm through density, hairlines, accent position. Chapter markers `01` `02` … `08`. Marker opener: Badge + h2 + Separator on every non-Hero chapter (one per chapter, no exceptions). Chapter divider for in-chapter rests, sparingly.

### AnimateNumber

`motion-plus/react` AnimateNumber. Children must be pure numeric string. Use `parseDisplayValue()` to split Bitable formatted values. Wrap in `inline-flex items-baseline gap-1 whitespace-nowrap`. `prefers-reduced-motion`: render plain text.

```jsx
import { AnimateNumber } from 'motion-plus/react'

// parseDisplayValue: split Bitable formatted value (e.g. "¥1,234,567.00" / "85%")
function parseDisplayValue(value) {
  if (value == null) return { prefix: '', number: '0', suffix: '' }
  const m = String(value).match(/^([^\d\-]*?)(-?[\d,]+\.?\d*)(.*)$/)
  if (!m) return { prefix: '', number: '0', suffix: '' }
  return {
    prefix: (m[1] ?? '').trim(),
    number: m[2].replace(/,/g, ''),
    suffix: (m[3] ?? '').trim(),
  }
}

// Usage in Hero / KPI focal numeral
const { prefix, number, suffix } = parseDisplayValue(displayValue)
<span className="inline-flex items-baseline gap-1 whitespace-nowrap">
  {prefix && <span style={{ color: 'var(--primary-hl)' }}>{prefix}</span>}
  <AnimateNumber
    style={{ color: 'var(--primary)' }}
    transition={{ type: 'spring', duration: 2.0, bounce: 0 }}
  >
    {number || 0}
  </AnimateNumber>
  {suffix && <span style={{ color: 'var(--primary-hl)' }}>{suffix}</span>}
</span>
```

## 18. Component Constraints

Use top-level hooks, typed props, `motion/react`, `motion-plus/react`, numeric easing arrays, `aria-hidden` for decorative visuals, semantic labels for readable values, `isAnimationActive={false}` on Recharts, reduced-motion fallbacks for AnimateNumber + WebGL + off-screen continuous motion.

Forbidden dial combinations (HARD):

- `impact` + `playful` radius — visual whiplash. Fallback: `radius=crisp`.
- `editorial` + `dense` density — undermines reading rhythm. Fallback: `density=balanced`.
- `technical` + `mesh` shader — readability conflict on data sections. Fallback: `hero_shader=dithering`.

Reject the page if any combination above is requested. Auto-fallback to the nearest legal pair before rendering (warn in console).

Removed dials (no user-facing control, fixed internally):

- `accent_strategy` — always `mono`; semantic colors removed.
- `neutral_temperature` — always branded chroma (C 0.008 light / 0.012 dark).
- `card_border` — always bordered (filled cards never carry visible border).
