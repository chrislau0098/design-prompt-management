## 1. Brand & Style

Mood: depends on `font_family`. Default vibe: **Restrained · Precise · Single-hue · Flat**.

Proposition: a parameterized campaign-report base. Dial values arrive via URL query (`?style=default&mode=...&color=...&lightness=...&font=...`); advanced dials (`hero=`, `radius=`, `density=`, `heroimg=`) auto-derive from STYLE_PRESETS[font_family] when not specified. Defaults: `mode=light` · `color=#1E40AF` · `lightness=0` · `font=geometric` · `heroimg=''`. `accent_strategy` removed — always mono/bordered. `neutral_temperature` removed — internal neutralC always branded. `card_border` fixed bordered.

Style presets (font_family → advanced dials):

| font_family | radius | density | hero_shader |
|-------------|--------|---------|-------------|
| geometric | sharp | balanced | mesh |
| editorial | sharp | sparse | mesh |
| technical | crisp | dense | dithering |
| warmth | friendly | balanced | grain |
| impact | crisp | balanced | mesh |
| ceremonial | sharp | sparse | mesh |

**STYLE_PRESETS shader assignment is mandatory, not advisory** — `geometric→mesh`, `editorial→mesh`, `technical→dithering`, `warmth→grain`, `impact→mesh`, `ceremonial→mesh`. Picking a non-preset shader for the routed `font_family` is a violation. The `hero_shader` dial overrides ONLY when the user explicitly supplies `?hero=` URL query (machine override). Natural-language keywords never override shader — they route `font_family`, and shader follows the preset mechanically. Keyword "SaaS / 增长" routes geometric → shader MUST be mesh, never dithering, even if "数据" appears in the brief.

## 2. Style Routing (User Keyword → font_family)

> **READ FIRST.** Before sampling tokens or assembling sections, parse the user's brief and route to ONE `font_family`. Every downstream choice (radius, density, hero_shader, font stacks, weight ceiling) follows.

**Keyword → font_family:**

| User keyword (CN + EN) | → font_family · (radius · density · hero_shader) |
|---|---|
| 自然 / 温暖 / 清新 / 教育 / 治愈 / 生活 / 美食 / 亲子 / 萌系 / nature / warm / fresh / cozy / lifestyle / food / kids | → **warmth** (friendly · balanced · grain) |
| 文艺 / 杂志 / 阅读 / 古典 / 编辑 / 印刷 / 出版 / 文化 / editorial / magazine / classic / publishing | → **editorial** (sharp · sparse · mesh) |
| 数据中心 / 工程 / 算力 / 监控 / 服务端 / 后端 / fintech / 仪表盘原始 / 工具底层 / data-center / backend / infrastructure / observability | → **technical** (crisp · dense · dithering) |
| SaaS / dashboard / 看板 / 增长 / 后台业务 / b2b / admin / saas / growth | → **geometric** (sharp · balanced · mesh) |
| 运动 / 户外 / 硬核 / 竞技 / 极限 / 速度 / 力量 / 工业 / sport / extreme / outdoor / industrial / heavy | → **impact** (crisp · balanced · mesh) |
| 庆典 / 国潮 / 喜庆 / 仪式 / 婚礼 / 传统 / luxury / 奢华 / festive / ceremonial / wedding / tradition | → **ceremonial** (sharp · sparse · mesh) |
| 通用 / 极简 / 严谨 / 商务 / 默认 / minimal / business / corporate / generic / 无信号 | → **geometric** (sharp · balanced · mesh) — **default** |

**Conflict priority:**

1. Explicit families win their own row, leftmost wins on row-1 ties: `impact > ceremonial > editorial > warmth`
2. SaaS / dashboard / 看板 / 增长 / 后台 → **geometric** (default tech-product visual language)
3. **technical** only when keywords explicitly contain 数据中心 / 工程 / 算力 / 监控 / 服务端 / 后端 / infrastructure / backend / observability
4. Generic `科技 / tech` alone (no infrastructure modifier) routes to **geometric**, not technical — geometric is the modern SaaS/增长 tech-product baseline
5. No signal → **geometric**

**Verbal color phrases** ("用红色") route through §3 brand color presets, not this table. Family routes from mood/business keywords only. Don't ask for clarification on tech keyword variance; commit to resolved route.

**Data semantic preservation (HARD):** Bitable input data carries the truth. User query determines brand identity + style language; never reinterpret metric meaning. Sales figures stay sales figures; revenue stays revenue; user counts stay user counts. Don't rename "销售额" → "击杀数", "经理" → "选手", "营收" → "得分". Numerical schema's semantic comes from Bitable, not the user's mood keyword. Re-skin the visual; preserve data label vocabulary verbatim.

## 3. Colors

Color space: OKLCH. **User-anchored expansion**: `brand_color` hex parses to (pL, pC, pH); `--primary` equals the user's color with optional `lightness_shift` offset; chart ramp ramps around the anchor; neutrals share `pH` only (their L/C follow the standardized ramp). `neutralC` always branded: 0.008 (light) / 0.012 (dark) — no user-facing dial.

### Brand color fidelity (HARD)

`--primary` MUST equal `oklch(primaryL pC pH)` where (pL, pC, pH) is the user's `brand_color` parsed through OKLCH. NEVER fall back to a neutral / gray / muted default; NEVER substitute a "safer" preset when chroma feels high. If hex parse fails, halt rendering — never synthesize a fallback brand color. The user's color is the design's emotional anchor.

### Light mode tokens (algorithm)

OKLCH function MUST use space-separated CSS Color Module Level 4 syntax — `oklch(L C H)` / `oklch(L C H / alpha)`, never comma-separated `oklch(L, C, H)` (legacy syntax invalid, falls back to initial value = black).

```
brand_color → (pL, pC, pH) in OKLCH; shift = lightness_shift / 100
primaryL     = clamp(pL + shift × 0.15, 0.30, 0.70)
--primary       = oklch(primaryL pC pH)
--primary-hl    = oklch(min(primaryL+0.10, 0.78) pC pH)
--primary-soft  = oklch(0.92 min(pC, 0.04) pH)
--primary-glow  = oklch(primaryL pC pH / 0.15)
--chart-1       = var(--primary)
--chart-2       = oklch(max(primaryL+0.07, 0.40) min(pC, 0.18) pH)
--chart-3       = oklch(max(primaryL-0.12, 0.22) max(min(pC-0.06, 0.14), 0.02) pH)
--chart-4       = oklch(max(primaryL-0.22, 0.18) max(min(pC-0.10, 0.10), 0.02) pH)
--chart-5       = oklch(max(primaryL-0.32, 0.15) max(min(pC-0.14, 0.06), 0.02) pH)
--background / --surface-l1 = oklch(0.985 neutralC pH)
--surface-l2 = oklch(0.965 neutralC pH); --surface-l3 = oklch(0.935 neutralC pH)
--foreground / fg-2 / fg-3 = oklch(0.14|0.42|0.62 0.008 pH)
--border = oklch(0.14 0.008 pH / 0.10); --border-strong = oklch(0.14 0.008 pH / 0.22)
--chart-hover  = oklch(primaryL pC pH / 0.08)   # light mode — brand-tinted translucent
--chart-hover  = oklch(primaryL pC pH / 0.12)   # dark mode  — same lightness, higher alpha
--quote-bg = oklch(0.965 neutralC pH); --outro-bg = oklch(0.985 neutralC pH)
```

Recharts `<Tooltip cursor={{ fill: 'var(--chart-hover)' }} />` (HARD) — `--chart-hover` is a brand-tinted translucent overlay. Lightness MUST equal `primaryL`; only alpha changes between modes. Don't hallucinate `oklch(14% ...)` or any low-lightness neutral derivation.

### Background lightness invariant (HARD)

Light mode `--background` and every `--surface-l*` MUST satisfy `L ≥ 0.95` unconditionally — no exceptions for any `brand_color` hue / `lightness_shift` value / user keyword. Dark mode `--background` MUST satisfy `L ≤ 0.16` unconditionally. `lightness_shift` only modulates `--primary` and chart ramp; NEVER touches bg / surface / foreground / border / any neutral token. Neutrals follow the standardized ramp above; only `--primary` and `--chart-*` accept user L offset.

### Dark mode tokens

Same accent algorithm; neutral L flips symmetrically — background 0.10 · surfaces 0.12 / 0.14 / 0.17 · foregrounds 0.92 / 0.70 / 0.50 · border alpha 0.14 / 0.28. Dark primaryL lifts by +0.10 (clamp 0.42–0.72) to maintain ≥ 4.5:1 contrast. `--primary-glow` alpha 0.18 in dark. `--primary-soft` in dark mode = `oklch(0.22 min(pC, 0.04) pH)` — a soft surface that stays distinct from `--surface-l1` at L = 0.12. **HARD: `--primary-soft` is a background-only token — NEVER appears as text `color`.** Use it on tag bg / chip bg / pill bg / soft accent surface only. Text color always comes from { `--foreground`, `--foreground-2`, `--foreground-3`, `--primary`, `--primary-hl` }.

### Brand color presets (verbal input)

When users say "用红色" instead of hex: `red #E03131` · `crimson #B83A3A` · `orange #F76707` · `amber #F59F00` · `green #00AC97` · `teal #0EA5E9` · `blue #1E40AF` *(default)* · `indigo #4F46E5` · `purple #7C3AED` · `pink #DB2777` · `slate #64748B` · `black #0F172A`. Priority: `?color=` > `?named=` > default.

### Neutral hue logic

Neutrals (surface / foreground / border / chart-hover) share `pH` with the accent. Use neutralC chroma (0.008 light / 0.012 dark) — never C=0.

### Foreground role discipline (HARD)

**FORBIDDEN BODY COLOR — HARD GATE.** EVERY `<p>` element MUST use `color: var(--foreground)` — regardless of `fontSize`, `text-sm`/`text-xs`, role, or visual position. The rule applies regardless of HOW the color is set — inline `style={{color:'var(--foreground-2)'}}`, className utility (`text-[var(--foreground-2)]`), or class CSS cascade rule (`.rep-eyebrow { color: var(--foreground-2) }` applied to a `<p>` element via className) — ALL are violations when the carrier is a `<p>` element. The CSS rule's selector path is irrelevant; the element type is. This covers (named, not exhaustive): Hero lead, Outro description, section intro paragraph, KPI label (the text above or below the focal number, including 13px/`text-xs` labels), Chapter body, Quote body, Insight statement, ranking-row description. A 13px `<p className="text-sm">` is still body — NOT a caption. **Meta-label element discipline (HARD).** Meta-label text — role / region / 职位 / 省区 / score caption / timestamp / colophon / eyebrow / ranking-role / quote-attribution / outro-colophon, typically 11–14px — MUST use `<span>` element, NOT `<p>`. If you reach for `<p className="text-xs">` or `<p className="rep-eyebrow">` carrying a meta-label, rewrite as `<span>` first. The `<p>` element is reserved for narrative body — Hero lead, Outro description, section intro paragraph, Chapter body, Quote body, Insight statement, ranking-row description, KPI label (above/below the focal number). `--foreground-2` is ONLY allowed on these specific NON-`<p>` carriers: Recharts axis `tick.fill`, Recharts legend `wrapperStyle.color`, `<span>` meta-labels per above, and inline `<span>` unit suffix inside a number (e.g. the `%` / `元` / `家` span next to KPI value). `--foreground-3` is ONLY for: decorative ornament marks, disabled states, non-essential timestamps. Don't `<p style={{color:'var(--foreground-2)'}}>` at any size. Don't `<p className="text-xs" style={{color:'var(--foreground-2)'}}>`. Don't justify with "this is a label/caption" — KPI labels and metric sub-text use `<p style={{color:'var(--foreground)'}}>` at the same `--foreground`. Body rides `--foreground` (L 0.14 light / L 0.92 dark); every `<p>`, every mode, no fontSize escape hatch.

### Color rules

- Focal numbers use `--primary`. Units, percent signs, delta arrows, delta values use `--primary-hl` (lighter L +0.10, same hue/chroma).
- Charts: single-hue ramp chart-1 → chart-5. Latest period = chart-1 brand accent; prior periods step to chart-3 → chart-5. Hover/active uses `--chart-hover`.
- Depth from Hero shader + chapter rhythm + typographic scale + brand accent — never shadow stacks. Borders whisper-thin (≤ 0.10 alpha); surfaces stack ≤ one L step.
- Card border rule: filled cards (`bg-surface-l2`, `bg-card`) carry NO visible border — fill OR border, never both. Transparent / non-filled cards may add ONE 1px hairline (`var(--border)` ≤ 22% alpha). NEVER nest a bordered wrapper inside another bordered card — ONE border layer per card, ONE radius per card. Heavy / dark borders are dividers only (chapter hairline / `<hr>`) — never card edges.
- Hero is not a chapter — no ChapterStamp / chapter numeral / kicker inside Hero. Hero ornament: eyebrow + Display Number + delta + lead only.
- Shader-induced contrast issues solve at the shader source — lower `colorFront` lightness/chroma directly. Never `backdrop-filter` / mask / opacity overlay on Hero shader (single-layer architecture).
- Brand accent 8–15% of every viewport. Reserved for focal numerals, chart-1 latest, Hero shader breath, chapter index, one structural accent per section.
- No `#000000`. No `#FFFFFF`. Tokens only.

### Chroma constraints (HARD)

| Token family | C ceiling (light) | C ceiling (dark) |
|---|---|---|
| Neutral (surface / foreground / border) | 0.008 | 0.012 |
| Accent (primary / primary-hl) | 0.22 | 0.22 |
| Chart 1–5 | 0.22 → 0.08 | 0.22 → 0.08 |
| Primary-soft (tag bg) | 0.04 | 0.04 |

Any token with C > ceiling = violation. Regenerate.

### Mandatory binding

`:root` sets `--title-stack` / `--number-stack` / `--body-stack` / `--mono-stack` from dial. `body { font-family: var(--body-stack) }`. `h1, h2, h3, .rep-hero-title, .rep-chapter-title { font-family: var(--title-stack) }`. `.rep-hero-num, .rep-kpi-num, [data-num] { font-family: var(--number-stack); font-feature-settings: "tnum", "lnum" }`. `.rep-eyebrow, .rep-colophon, [data-meta] { font-family: var(--mono-stack) }`.

### Font fidelity (HARD)

The `font_family`-routed display face is a HARD requirement, not an optional preference. The first font in each stack carries the design intent; stack order is non-negotiable. If the primary face fails to load, the page MUST visibly degrade through the declared fallback chain (system serif for editorial / ceremonial, system sans for geometric / warmth, system monospace for technical, condensed display for impact) — never silently substitute a generic default. Always declare the full stack as listed; never truncate; never swap to a "safer" generic.

Forbidden as rendered: Inter, system-ui, DM Sans (as primary geometric), Arial. `editorial` → serifs must be visible (Spectral / EB Garamond). `warmth` → Nunito / Comfortaa rounded forms visible; CJK uses LXGW WenKai TC for title only — NEVER body. `impact` → CJK heavy/condensed shape visible. `ceremonial` → EB Garamond drives English title, pairs with Ma Shan Zheng / Zhuque Fangsong CJK; 装饰字体 NEVER on body.

| editorial | 700 | 400 | 700 |

### Scale

| Level | lg | mobile | Weight |
|---|---|---|---|
| Page Title | `text-[120px]` | `text-[56px]` | Display |
| Display Number | `text-[200px]` | `text-[96px]` | Display |
| Section Primary / Secondary / Tertiary | 80 / 48 / 28px | — | Display / Display / Body |
| Quote | 36px | — | Body |
| Body / Caption | 15 / 13px | — | Body |
| Meta-Label / Eyebrow | 11px | — | Display, `tracking-[0.08em]` / `[0.16em]` |

Display Number: `leading-[0.86]` `tracking-[-0.04em]`. Exact breakpoint classes — no `clamp()` (sub-pixel jitter degrades AnimateNumber spring). Anatomy: focal figure scale `--primary`; unit suffix ~28–30% figure height, baseline-aligned `gap-2`, `--primary-hl`. Never same scale as figure, never above baseline, never wrapped.

OpenType: `font-feature-settings: "kern", "tnum", "lnum"` on all data numbers. `technical` adds `"calt"`.

CJK: primary sans for Hero Title, Chapter Title, Body, Caption; `--number-stack` for Display Number Latin only; `textWrap: "balance"`; `max-w-[42ch]` body / `max-w-[18ch]` hero; 0.1em space flanking digits in mixed lines.

Body: `text-[15px]` / 13px caption, body weight, `--foreground` prose. Chapter title: claim-line (5–14 CJK / 4–9 EN), Section Primary, Display weight, `--foreground` — never slogan, never ALL-CAPS (except `impact` / `technical`), never question. Hierarchy: one Primary number per section; tiers differ ≥ 2 steps; emphasis from scale + color, never italic, never bold above ceiling.

**Hero Display Number size — HARD GATE.** Size MUST be inlined at the call site or wrapper root element as Tailwind mobile-first exact classes (e.g. `className='text-[96px] md:text-[200px]'`). Do NOT use `clamp()` (§4 carry-over). Do NOT rely on parent inheritance — a wrapper without an explicit size prop falls back to silent default (16px). Mobile-first order: `text-[96px] md:text-[200px]`, never reverse.

**Wrapper className delegation — HARD.** If a custom abstraction wraps Display Number (e.g. for `AnimateNumber` integration), the wrapper MUST (1) accept a `className` prop and apply it to its root element, OR (2) set the size directly on the root element. Size cannot be the responsibility of the wrapper's parent container — parent inherit = silent default = invalid.

### Focal numeric length-based scale step

Apply length-based conditional className on Display Number from `displayNumber.length`: ≤ 7 char → default scale / 8–11 char → drop one tier / ≥ 12 char → drop two tiers. Parent `min-w-0` AND child `whitespace-nowrap`. Don't rely on `min-w-0` alone or `clamp()`.

|---|---|---|

## 7. Motion

Engines: `motion/react` · `motion-plus/react` (AnimateNumber) · `@paper-design/shaders-react` (Hero shader, per `hero_shader` dial).

> **FORBIDDEN IMPORT — HARD GATE.** ALL `motion` / `useReducedMotion` / `useInView` / `AnimatePresence` / `LayoutGroup` / `MotionConfig` imports MUST come from `motion/react`. Importing from `framer-motion` is forbidden — that package no longer exists for this design system. `AnimateNumber` MUST come from `motion-plus/react`. No exceptions. Don't `import { motion } from 'framer-motion'`. Don't `import { useReducedMotion } from 'framer-motion'`. Use `import { motion, useReducedMotion, useInView } from 'motion/react'`.

```ts
const EASE = {
  out:   [0.16, 0.84, 0.24, 1],
  inOut: [0.7,  0,    0.3,  1],
  snap:  [0.18, 0,    0.05, 1],
  spring:[0.4,  0,    0.3,  1],
}
```

| Category | Duration | Easing |
|---|---|---|
| Hover | 150ms | out |
| Button press | 100ms | snap |
| Element entrance | 500–900ms, y: 32–36px | out |
| Number rolling | 1.2–2.0s | spring, no bounce |
| Curve pathLength | 2.0–2.8s | out |
| WebGL Hero | viewport-paused | speed per shader |

Entrance: Hero uses `animate=` with delays. Section shells, body paragraphs, chart wrappers, prose render visible on first paint without animation wrappers.

Every `whileInView` must pair `viewport={{ once: true, margin: "0px 0px -15% 0px" }}` — no exceptions.

Stagger: `staggerChildren: 0.1` from `"first"`. Reduce by 0.02 on mobile.

Motion per viewport: one focal motion only. Hero staged reveal → Time Series area draw → Proportion rail fill → Ranking cascade → Annotation donut → Quote crossfade → Outro signature glow. Vary by archetype.

### Reduced-motion adoption (per-primitive · HARD)

`useReducedMotion()` mandatory at every motion primitive declaration site, imported from `motion/react` only. Three call sites carry hard requirements:

1. **AnimateNumber wrapper** — read at wrapper top; when true render formatted static text (no spring, no digit roll); reduced users see final number immediately
2. **`motion.div whileInView`** — read at each declaration (cluster cells, annotation rail, sequence rows); when true skip `initial → whileInView` transition, render visible final state immediately, no `y/opacity` interpolation
3. **Hero shader speed** — read at each `MeshGradient / GrainGradient / Dithering` site; when true override `speed=0` in shader props before mounting

Don't rely on a single trailing CSS `prefers-reduced-motion` block — the rule lives inline at each motion primitive. CSS `@media (prefers-reduced-motion: reduce)` fallback for non-React animation: `animation-duration: 0.01ms !important`, opacity crossfade only. WebGL shaders accept `speed: 0` directly from React state — don't pause via CSS.

### AnimateNumber scope


SVG: `pathLength: 0→1` draw-in. No `d` morph.

Data-driven invariant: null/undefined → render empty state, not broken animation.

## 10. Do's and Don'ts

Do:
- Neutral ground 60% / brand accent 8–15% / prose rest. ChapterStamp opener on every non-Hero chapter (variant per `font_family` — see §15)
- Focal numerals `--primary`; units/percent/delta `--primary-hl` inline baseline. Hero leads with Display Number + paragraph subtitle. Body / lead / chapter-body prose ride `--foreground` full contrast
- Single-hue chart ramp chart-1 → chart-5. Latest period = brand accent; older steps to chart-3 → chart-5. One structural visual decision per viewport beyond color
- Hero shader single-layer: contrast adjustments at shader `colors[].L` / `colors[].C` — never wash overlay
- Preserve Bitable schema labels verbatim — re-skin the visual, not the data vocabulary
- Import all motion primitives from `motion/react` and `motion-plus/react` only. Wire `useReducedMotion()` at every motion site (AnimateNumber wrapper, `whileInView`, shader speed)
- Hold light mode bg at `L ≥ 0.95`, dark mode bg at `L ≤ 0.16`. `lightness_shift` only modulates `--primary` and chart ramp — never bg / surface / neutral
- Render `--primary` from the user's `brand_color` OKLCH parse — never silently substitute a gray, muted, or "safer" preset

Don't:
- Import from `framer-motion`. ANY `import ... from 'framer-motion'` line is a hard violation — replace with `motion/react`
- Apply `lightness_shift` to bg / surface / foreground / border / any neutral token — it modulates `--primary` and chart ramp only

- Stack two borders on same card. One border layer per card, one radius per card. No Double-Bezel in default style

Outro caps the report with a colophon line + radial glow, full stop. Any pill/button/CTA visual = hard violation regardless of HTML element used. Campaign Report is read-only narrative, not landing page

- Recontextualize data semantic (sales → kills, revenue → score). Brand voice owns visual; data labels stay verbatim. Repeat same panel material every chapter — vary by archetype
- Fade whole sections opacity-only, repeat identical `y + opacity` reveals, or animate CSS layout. Animate `transform` and `opacity`

## 11. Pattern Overview

Story told in data, not a dashboard. Narrative arc: opening hook → supporting evidence → closing impact. Each section advances one beat. One focal claim + one supporting visual per section. Reader leaves with three things: headline number, the why, the so-what. Archetype names are internal labels — visible eyebrows/captions come from topic, period, data role, business meaning.

### Scope

Scrollable single-page data narrative where numbers are protagonist. Density Low → High (rhythm-controlled); strong archetype alternation; arc Beginning → Middle → End.

Data shapes: time-series · proportions · paired metrics · ranking · grouped metrics · event sequence · peer catalog · annotation.

### Voice

Third-person observational. `we` only in attribution. Statements not CTAs: `Bookings closed at 142,300`. Eyebrows: uppercase mono `tracking-[0.16em]`. Titles: sentence case, no terminal period (`impact` / `technical` allow ALL CAPS Hero title). Body: sentence case full sentences. Numbers: tabular figures, thousands separators, no decimal padding. Period strings: `·` middle dot (U+00B7) + single spaces.

Inline comparison phrase: `从 ¥30.9亿 (2025) 至 ¥36.5亿 (2026) ▲ 18.2%` — one editorial line, baseline-aligned, no `vs` layout.

> Default skeleton stays data-led (Pattern Overview "numbers are protagonist"). Alpha 0.15 light / 0.18 dark. `prefers-reduced-motion`: opacity 0.6. **Outro material discipline — HARD GATE.** Typographic Field treatment ONLY. NO `backgroundColor` (on the outer section element), NO `borderRadius`, NO rounded surface panel chrome on the outer section. The radial `--primary-glow` `::before` pseudo-element is the only decorative layer. Body content is plain `<p>` paragraphs over `var(--background)` ground.

**Brand Narrative Spine** — Narrative-led, data as supporting evidence. Engages on brand-history / heritage / craftsmanship / founder-story triggers. Structure: opening anecdote → period of origin → craftsmanship detail → present-moment data inlay → future intent. Treatments: Typographic Field heavy + Asymmetric Split (craft visual / long-form prose). Density: long-form prose paragraphs dominate page volume (multiple substantial paragraphs per section, full-sentence narrative not fragments). Number frequency: low (handful of distinct figures whole-page), figures blend into prose sentences rather than standalone display blocks, AnimateNumber reserved for focal claim only. Anti-refs: NEVER render as KPI Cluster grid / chart-as-hero / grid-of-cards. Brand story is the spine, not the side-bar.

**Testimonial-Threaded** — Customer voice interleaved with data points (NOT split-card). Engages on customer-voice / testimonial / case-interview triggers. Structure: alternating Stacked Band where each band pairs a brief quote (en-dash lead-in, attribution per §3 Meta-label discipline) with one inline data sentence that the quote substantiates. HARD GATE: NEVER render quotes and data as two parallel columns / two consecutive sections (quote block + data block split) / card-of-quote with shadow / border / rounded-card chrome. Quote and supporting data MUST sit within the same section / band, visually adjacent, voice-then-evidence rhythm. Quote brevity extends Quote Interstitial's compact cap (single short statement, not paragraphs); Quote Interstitial archetype itself remains unchanged for non-threaded use. Anti-refs: NEVER use shadcn Card or panel chrome — bare typography only.

## 13. Composition

> Default composition skeleton assumes data-led narrative (Pattern Overview "numbers are protagonist"). When Brand Narrative Spine OR Testimonial-Threaded archetype trigger explicitly matches the user query, that archetype's own structure recipe overrides the default skeleton below; otherwise the default skeleton applies and the new archetypes do NOT activate.

Default: Hero → KPI Cluster → Time Series → Timeline → Key Insights → Ranking → Proportion → Annotation Rail → Quote → Outro. Section count follows data; stop before filler.

### Rhythm

1. **Density rotation** — adjacent differ (dense / medium / spacious); no two consecutive dense.
2. **Treatment variety** — no two consecutive same treatment or archetype.
3. **Bold-move budget** — disruptive ≤ ceil(N × 0.25).
4. **Break cadence** — ≥ 1 section uses Full-bleed, Offset, or Typographic Field. Hero + Outro satisfy.

### Rules

Ground consistent across chapters; vary rhythm through density, hairlines, accent position. Chapter markers `01` `02` … `08`. ChapterStamp opener on every non-Hero chapter (one per chapter, no exceptions; variant rendered per `font_family` per §15). Chapter divider for in-chapter rests, sparingly.

### Charts dark-mode tooltip (HARD)

`<Tooltip content>` MUST inline mode-explicit hex (not CSS variables) because Recharts Tooltip wrappers escape the canvas dark subtree. Pass the current `mode='light' | 'dark'` into the render function and map to literal hex:

Apply literal hex on container background / border / color, label color, value color, series-name color. Fixed styles (no provider) keep variable-based behavior.

### 14.1 Hero Monolith (default style — 2-col grid HARD GATE)

Focal: primary-value Display Number, `--number-stack`, Display weight, `--primary`, inline unit `--primary-hl`, animated count-up via AnimateNumber. Background: page-level `var(--background)` ground + Hero shader per `hero_shader` dial OR image background per `hero_image_url` dial (mutually exclusive — see §15 Hero image archetype). **Default style Hero composition — HARD GATE.** Default style Hero root MUST use CSS grid: `display: grid; grid-template-columns: 1.15fr 1fr; gap: 48px 56px; align-items: end`. NO flex column / NO block stacking / NO single centered column at desktop. Left col: eyebrow + h1 title (`max-w-[18ch]`) + lead paragraph (`max-w-[44ch]`, `--foreground`). Right col: Display Number (text-align right) + delta indicator stacked below. Container query `@container report (max-width: 800px)` flips to single-column grid (`grid-template-columns: 1fr`, `align-items: start`, right col text-align left). Missing `display: grid` on Hero root is a design violation, not an artistic choice. Fixed styles keep vertical Typographic Field — grid HARD GATE applies to default style only. When the Hero `<section>` carries `min-h-[Xvh]` / `min-h-screen` (occupying viewport height), the grid root element AND any intermediate wrapper between section and grid MUST satisfy `min-height: 100%` (Tailwind: `min-h-full`). Without this, the grid container only spans natural content height, and `align-items: end` aligns content to that natural bottom — typically section's upper 1/3 — leaving the lower 2/3 as empty shader. The section's `min-h` is the layout floor; everything between section and grid items must propagate that floor for `align-items: end` to reach section's true bottom.

Hero brand marks: focal numeral, delta indicator, shader breath (or image dim overlay when image mode active).

Anti-refs: don't set Hero on saturated brand-hue ground; don't use product photos as inline figures (Hero background image is a separate archetype, see §15); don't stack banners or KPI grids in Hero; don't pair brand accent with a second hot accent; don't add a `.rep-hero-shader-wash` linear gradient overlay (single-layer rule).

**Hero focal number readability — HARD GATE.** The focal number must satisfy ≥ 4.5:1 contrast against the underlying shader / image color at the number's bounding box. Two paths, prioritized:
(1) **Primary path.** Constrain the shader / image so the region under the number is extreme L — light mode: that region's authored L > 0.92 (near-white); dark mode: that region's authored L < 0.20 (near-black, aligned with §17 dark mesh/grain `colorBack` 0.125–0.155). This is a design-time constraint on the colors[] / image composition, not a runtime sample. The number's bounding box MUST be framed within the colors[] darkest entries (e.g. `colorBack` for dithering/grain, or the darkest swatch in mesh's 5-color array) — not in the brand-peak or neighbor-accent region.
(2) **Fallback only when (1) cannot be guaranteed** (e.g. mesh genuinely produces a mid-tone region under the number): add a `--surface-l2` solid-color local backplate beneath the number — a tight `inline-flex` container with `backgroundColor: var(--surface-l2)`, `padding: 12–24px`, `borderRadius: var(--radius-card)`. Adding a backplate when shader L already extreme = unnecessary panel chrome = HARD violation.
NEVER use `.rep-hero-shader-wash` linear-gradient mask, `backdrop-filter blur`, or full-Hero opacity overlay to fix this — these violate the §14.1 single-layer rule (above carry-over). Option 1 is the default path; option 2 is fallback only when option 1 cannot be guaranteed. This rule shapes the visual context around the number, not the number itself — AnimateNumber JSX implementation (§17) remains unchanged.

Primary-value selection: (1) rate/percentage → avg, (2) aggregate keyword → sum, (3) primary metric → max, (4) same → avg. If missing, omit Hero.

No exceptions — even the brand-anchored swatch projects its L onto this range; the raw `brand_color` L is never passed through. Violating L = shader has mid-tone region where Hero focal text fails 4.5:1 contrast. Policy: 1 WebGL instance per page (Hero only); `speed_off_viewport: 0` (IntersectionObserver toggles); CSS fallback `backgroundColor=var(--background)`; foreground image OK iff user-provided (see Hero image archetype §15); NO wash overlay on shader; scope Hero ONLY; **reduced-motion**: read `useReducedMotion()` from `motion/react` and pass `speed=0` when true.

### Hero shader · minimum React snippets

> The ONLY place in this prompt React snippets are allowed. Copy the shape verbatim, fill `colors` from §3 OKLCH ramps. All other chapters render as plain JSX without snippets. All WebGL shaders share wrapper `SHADER_STYLE = {position:'absolute', inset:0, width:'100%', height:'100%', zIndex:0}`. paper-shaders does not parse `oklch()` — feed `colors` / `colorBack` / `colorFront` as hex strings. ### AnimateNumber

`motion-plus/react` AnimateNumber. Children pure numeric only. Use `parseDisplayValue()` to split Bitable formatted strings. Wrap in `inline-flex items-baseline gap-1 whitespace-nowrap`. **Reduced motion (HARD)**: `useReducedMotion()` at wrapper top; when true render static parsed text. **Tabular numerics (HARD)**: every call site MUST inline `style={{ fontFeatureSettings: '"tnum" 1, "lnum" 1', fontVariantNumeric: 'tabular-nums lining-nums', letterSpacing: 0 }}` on BOTH outer wrapper span AND `<AnimateNumber>` itself. Reason: AnimateNumber renders each digit position into a fixed-width Mask scrolling 0-9 inside; proportional fonts (Geist, EB Garamond, Ma Shan Zheng) have differing digit advances → Mask under-sizes, digits overlap. `tnum` + `tabular-nums` forces equal advance.

```jsx
import { useReducedMotion, useInView } from 'motion/react'
import { AnimateNumber } from 'motion-plus/react'
const TABULAR = { fontFeatureSettings: '"tnum" 1, "lnum" 1', fontVariantNumeric: 'tabular-nums lining-nums', letterSpacing: 0 }
const reduced = useReducedMotion()
const ref = useRef(null)
const inView = useInView(ref, { once: true, margin: '0px 0px -10% 0px' })
const { prefix, number, suffix } = parseDisplayValue(displayValue)

<span ref={ref} className="inline-flex items-baseline gap-1 whitespace-nowrap" style={TABULAR}>
  {prefix && <span style={{ color: 'var(--primary-hl)' }}>{prefix}</span>}
  {reduced
    ? <span style={{ ...TABULAR, color: 'var(--primary)' }}>{number}</span>
    : <AnimateNumber style={{ ...TABULAR, color: 'var(--primary)' }}
        transition={{ type: 'spring', duration: 2.0, bounce: 0 }}>
        {inView ? Number(number) : 0}
      </AnimateNumber>}
  {suffix && <span style={{ color: 'var(--primary-hl)' }}>{suffix}</span>}
</span>
```

## 18. Component Constraints

Use top-level hooks, typed props, `motion/react`, `motion-plus/react`, numeric easing arrays, `aria-hidden` for decorative visuals, semantic labels for readable values, `isAnimationActive={false}` on Recharts, per-primitive `useReducedMotion()` for AnimateNumber + WebGL + `whileInView` motion.divs.

Forbidden dial combinations (HARD): `impact` + `playful` radius (fallback `radius=crisp`) · `editorial` + `dense` density (fallback `density=balanced`) · `technical` + `mesh` shader (fallback `hero_shader=dithering`) · `hero_image_url` non-empty + `hero_shader` non-none (mutually exclusive; when image URL provided, ignore `hero_shader`). Reject the page if any combination above is requested. Auto-fallback to the nearest legal pair before rendering (warn in console).

Removed dials (no user-facing control, fixed internally): `accent_strategy` always `mono` (semantic colors removed) · `neutral_temperature` always branded chroma (C 0.008 light / 0.012 dark) · `card_border` always bordered (filled cards never carry visible border).
