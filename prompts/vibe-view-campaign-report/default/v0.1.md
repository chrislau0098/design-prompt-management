## 1. Brand & Style

Mood: depends on `font_family` × `accent_strategy` × `radius`. Default vibe: **Restrained · Precise · Single-hue · Flat**.

Proposition: a parameterized campaign-report base. Dial values arrive via URL query (`?style=default&mode=...&color=...&lightness=...&font=...&hero=...&radius=...&density=...&accent=...`); every visual decision resolves against the current dial set. Defaults: `mode=light` · `color=#1E40AF` · `lightness=0` · `font=geometric` · `hero=mesh` · `radius=sharp` · `density=balanced` · `accent=mono`. `neutral_temperature` removed — internal neutralC always branded.

## 2. Colors

Mode: depends on `mode` dial. Color space: OKLCH. **User-anchored color expansion**: the `brand_color` hex is parsed to (pL, pC, pH); `--primary` equals the user's color (with optional `lightness_shift` offset); chart ramp ramps around the anchor; neutrals share `pH` only (their L/C use the standardized ramp).

### Light mode tokens (algorithm)

```
(pL, pC, pH) = hexToOKLCH(brand_color)
primaryL = clamp(pL + lightness_shift / 100 × 0.15, 0.30, 0.70)

--primary       = oklch(primaryL,                 pC,            pH)
--primary-hl    = oklch(min(primaryL+0.10, 0.78), pC,            pH)
--primary-soft  = oklch(0.92,                     min(pC, 0.04), pH)
--primary-glow  = oklch(primaryL,                 pC,            pH, 0.15)
--chart-1       = var(--primary)
--chart-2       = oklch(primaryL + 0.07,          pC - 0.02,     pH)
--chart-3       = oklch(primaryL - 0.03,          pC - 0.06,     pH)
--chart-4       = oklch(primaryL - 0.13,          pC - 0.10,     pH)
--chart-5       = oklch(primaryL - 0.23,          pC - 0.14,     pH)
--background    = oklch(0.985, neutralC, pH)
--surface-l1    = oklch(0.985, neutralC, pH)
--surface-l2    = oklch(0.965, neutralC, pH)
--surface-l3    = oklch(0.935, neutralC, pH)
--foreground    = oklch(0.14,  0.008,    pH)
--foreground-2  = oklch(0.42,  0.008,    pH)
--foreground-3  = oklch(0.62,  0.008,    pH)
--border        = oklch(0.14,  0.008,    pH, 0.10)
--border-strong = oklch(0.14,  0.008,    pH, 0.22)
--chart-hover   = oklch(0.14,  0.008,    pH, 0.05)
--quote-bg      = oklch(0.965, neutralC, pH)
--outro-bg      = oklch(0.985, neutralC, pH)
```

`neutralC` always branded: 0.008 (light) · 0.012 (dark). No user-facing dial.

### Dark mode tokens

Same accent algorithm; neutral L flips symmetrically — background 0.10 · surfaces 0.12 / 0.14 / 0.17 · foregrounds 0.92 / 0.70 / 0.50 · border alpha 0.14 / 0.28. Primary lifts via the same algorithm to maintain ≥ 4.5:1 contrast.

### Brand color presets (when user describes verbally)

When users say "用红色" instead of giving hex, use these defaults (each is a single anchor hex; `lightness_shift` can fine-tune):

`red #E03131` · `crimson #B83A3A` · `orange #F76707` · `amber #F59F00` · `green #00AC97` · `teal #0EA5E9` · `blue #1E40AF` (default) · `indigo #4F46E5` · `purple #7C3AED` · `pink #DB2777` · `slate #64748B` · `black #0F172A`

### Neutral hue logic

Neutrals (surface / foreground / border) share `pH` with the accent. OKLCH `L` is perceptually uniform across hues — same `L` value works at any hue. Chroma controls how neutral the gray reads:

Neutrals always use branded chroma: C 0.008 (light) / 0.012 (dark). This gives warm gray under hue 30 (amber) and cool gray under hue 232 (blue), achieving emotional brand cohesion. No user-facing dial.

### Color rules

- Focal numbers use `--primary` (L 0.48 C 0.22). Units, percent signs, delta arrows, delta values use `--primary-hl` (lighter L 0.58, same hue/chroma).
- Charts: single-hue ramp chart-1 → chart-5. Latest period = chart-1 brand accent; prior periods step to chart-3 → chart-5. Hover/active uses `--chart-hover`.
- Depth from Hero shader + chapter rhythm + typographic scale + brand accent — never shadow stacks. Borders whisper-thin (≤ 0.10 alpha); surfaces stack ≤ one L step.
- Filled cards never carry visible borders — fill OR border, never both. Non-filled card borders stay `var(--border)` ≤ 12% alpha. Heavy / dark borders are dividers only (`<hr>` / chapter hairline) — never card edges.
- Hero is not a chapter — no ChapterStamp / chapter numeral / kicker inside Hero. Hero ornament: eyebrow + Display Number + delta + lead only.
- Shader-induced contrast issues solve at the shader source — lower `colorFront` lightness/chroma directly. Never `backdrop-filter` / mask / opacity overlay.
- Brand accent 8–15% of every viewport. Reserved for focal numerals, chart-1 latest, Hero shader breath, chapter index, one structural accent per section.
- No `#000000`. No `#FFFFFF`. Tokens only.

### Chroma constraints (HARD)

| Token family | C ceiling (light) | C ceiling (dark) |
|---|---|---|
| Neutral (surface / foreground / border) | 0.008 | 0.012 |
| Accent (primary / primary-hl) | 0.22 | 0.22 |
| Chart 1–5 | 0.22 → 0.08 | 0.22 → 0.08 |
| Primary-soft (tag bg) | 0.04 | 0.04 |

Any token with C > ceiling = violation. Regenerate.

## 3. Typography

`font_family` dial drives the full type stack. Six families, each with Latin and CJK pair. Three CSS vars are injected: `--display-stack` (titles/numerals), `--sans-stack` (CJK Display), `--body-stack` (body prose). Body text elements use `var(--body-stack, var(--sans-stack))` — the fallback keeps 6 fixed styles working.

### Mandatory binding

```css
:root { --font-family: <family-stack-from-dial>; }
body, * { font-family: var(--font-family); }
```

Forbidden as rendered: Inter, system-ui, DM Sans (when geometric), Arial. `editorial` → serifs must be visible. `warmth` → CJK fonts (LXGW WenKai) MUST come first. `impact` → CJK heavy/condensed shape visible.

## 4. Spacing & Layout

`density` dial drives spacing rhythm.

| Density | Section py (lg) | Grid gap | Cols |
|---|---|---|---|
| **sparse** | 160-200px | 8-12px | 2-3 |
| **balanced** *(default)* | 96-128px | 24-32px | 3-4 |
| **dense** | 48-72px | 16-24px | 4-6 |

Base unit: 8px. Scale: `1` `2` `3` `4` `6` `8` `12` `16` `24`. Section `px-6` mobile → `px-16` desktop. Container: `max-w-7xl` paragraph-driven; `max-w-5xl` KPI/chart. Grid: `gap-2`, `items-baseline`, `min-w-0`.

Long-scroll cadence: chapters stack vertically, separated by hairline + accent ornament. Content determines height, `min-h-[80vh]` floor. Overflow: truncate, wrap, or scale to longest plausible value.

Density: one observation per viewport. Gaps: `gap-1` tight · `gap-3` label+number · `gap-8` paragraph→KPI · `gap-12` KPI→chart.

KPI row: 4-6 cells, vertical hairline column rule, Display Number + unit + caption each. `px-6 py-4`; first `pl-0`. Stack below `md:` with horizontal hairline.

## 5. Material

`radius` dial drives corner system.

| Token | Value | Vibe |
|---|---|---|
| **sharp** *(default)* | 0px | systematic / editorial / minimal |
| **crisp** | 2px | instrumental / fintech |
| **soft** | 6px | saas / dashboard |
| **friendly** | 12px | consumer / lifestyle / 温暖 |
| **playful** | 16px | 节庆轻盈 / 教育 |

ONE radius per page. Pill/tag radius = sharp 0px always (regardless of dial) — pills stay sharp for chart legends and data labels even when card radius is friendly/playful.

```css
:root { --radius: <radius-value>px; }
```

Surface: flat ground from `var(--background)` token (no page-level shader). Hero shader is the page's only WebGL layer, scoped to Hero section. Panels lift through hairline + one-step L difference — never shadow stacks or backdrop-blur.

Borders: Whisper `1px solid var(--border)` · Strong `var(--border-strong)`. Shadow: none on cards (default). `accent_strategy=semantic` allows `inset-light` on Double-Bezel cards only.

Card variants (auto from `accent_strategy`):
- **borderless** *(from `silent`)*: minimalist, editorial, sparse. Image flush; title/desc left-aligned below image; spacing via `mt-*`; no wrapper border, no `bg-card`.
- **bordered** *(from `mono` / `semantic`)*: balanced/dense, dashboards. Wrapper `border` + `bg-card`; inner `.card-content` `p-5`/`p-6`.

ONE variant per page. NEVER mix.

Chapter opener: `ChapterBanner` — chapter index numeral + chapter title + `Separator` full-width below. Numeral typography per `font_family`. No SVG stamp / solid-fill / banner kicker unless dial = `ceremonial` (then SealStamp allowed).

Chapter divider: `oklch(1 0 0 / 0.08) h-px` (light) / `oklch(0 0 0 / 0.12) h-px` (dark). In-chapter rest only.

Panel discipline: `rounded-[var(--radius)]` chart frames and card chrome. Each archetype one material logic.

## 6. Motion

Engines: `motion/react` · `motion-plus/react` (AnimateNumber) · `@paper-design/shaders-react` (hero shader, conditional on `hero_shader` dial).

```ts
const EASE = {
  out: [0.16, 0.84, 0.24, 1],
  inOut: [0.7, 0, 0.3, 1],
  snap: [0.18, 0, 0.05, 1],
  spring: [0.4, 0, 0.3, 1],
};
```

| Category | Duration | Easing |
|---|---|---|
| Hover | 150ms | out |
| Button press | 100ms | snap |
| Element entrance | 500-900ms, y: 32-36px | out |
| Number rolling | 1.2-2.0s | spring, no bounce |
| Curve pathLength | 2.0-2.8s | out |
| WebGL Hero | viewport-paused | speed per shader |

Entrance: Hero uses `animate=` with delays. Section shells, body paragraphs, chart wrappers, prose render visible on first paint without animation wrappers.

Every `whileInView` must pair `viewport={{ once: true, margin: "0px 0px -15% 0px" }}` — no exceptions. Without `once: true`, elements reset to initial (opacity 0 / scaleX 0) on scroll-out and disappear.

Stagger: `staggerChildren: 0.1` from `"first"`. Reduce by 0.02 on mobile.

Motion per viewport: one focal motion only. Hero staged reveal → Time Series area draw → Proportion rail fill → Ranking cascade → Quote crossfade → Outro signature. Vary by archetype.

### AnimateNumber scope

Wrap every key number: Hero primary, section focal claim, Comparison left/right, Ranking top-1, Cluster cell headlines. Do not wrap labels, ordinals, dates, axis values. Cap ≤ 3 per section. `AnimateNumber` accepts pure numeric strings only — use `parseDisplayValue()` to split Bitable formatted values.

SVG: `pathLength: 0→1` draw-in. No `d` morph.

`prefers-reduced-motion`: `animation-duration: 0.01ms !important`; opacity crossfade only; WebGL `speed: 0`; AnimateNumber plain text.

Data-driven invariant: null/undefined → render empty state, not broken animation.

## 9. Do's and Don'ts

Do:
- Neutral ground 60% of viewport; brand accent 8-15%; prose the rest. Open every chapter with the chosen chapter opener.
- Focal numerals in `--primary`; units/percent/delta in `--primary-hl` inline at baseline. Hero leads with confident Display Number + paragraph subtitle.
- Single-hue chart ramp chart-1–5. Latest period brand accent; older step to chart-3–5.
- One structural visual decision per viewport beyond color.

Don't:
- Render focal numerals in `--foreground` — digits use `--primary`; prose holds the foreground.
- Use unauthorized accent palettes outside `--brand-hue`. No heavy shadows, frosted glass, `backdrop-blur`, rim lighting, card-edge glow, text glow.
- Use `rounded-xl`/`rounded-2xl`/`rounded-3xl`/blob/`rounded-full` on cards (pill/tag exception, see §5). One radius per page.
- Nest panels beyond one level or wrap sections in page-level containers.
- Use Inter, Roboto, Space Grotesk, Plus Jakarta (unless `warmth`), or overused faces outside declared stacks.
- Apply weight above family ceiling. Body / Lead remains 400-500 (warmth allows 500 ceiling).
- Repeat same panel material every chapter. Vary by archetype.
- Fade whole sections opacity-only, repeat identical `y + opacity` reveals, or animate CSS layout properties. Animate `transform` and `opacity`.
- Tween numbers as single value or duplicate unit/percent; per-digit spring only.
- Use ease strings; cubic-bezier arrays only. Use `min-h-dvh` not `h-screen`.
- Render text below `text-[10px]`; required reading `text-[14px]+`.
- Wrap every number in AnimateNumber — reserve for key claim numbers.
- Use `whileInView` without `viewport={{ once: true, margin: "0px 0px -15% 0px" }}`.
- Use `useScroll`/`useTransform`/`scrollYProgress` for Hero exit or scroll-linked parallax.
- Use ScrambleText, Typewriter, Ticker, character-level reveal.
- Introduce a second hot accent for delta-down or error. Neutral foreground carries those (semantic accent dial exception).
- Animate bar chart bars rising from zero — bars render static; highlighted bar uses `clip-path` reveal once.
- Animate paragraph reveal as reader scrolls. Prose visible on first paint.
- Wrap chapter `<section>` containers, chart wrappers, KPI grids, body paragraphs, or whole-page content blocks in `motion.div` with `initial={{ opacity: 0 }}` + `whileInView`. These render visible on first paint.

## 10. Pattern Overview

This page is a story told in data, not a dashboard — every section is a chapter, every chart is evidence for a claim. The narrative arc runs across the whole page: opening hook → supporting evidence → closing impact. Each section advances exactly one beat of the arc.

Each section carries one focal claim and exactly one supporting visual (chart, ranking, or quote). Parallel KPI tiles, side-by-side metric grids, and three competing focal numbers belong to a dashboard, not a campaign report.

A successful page lets the reader leave with three things: the headline number, the why behind it, the so-what of it.

Archetype names are internal planning labels only. Visible eyebrows, captions, and labels come from topic, period, data role, or business meaning — not section archetype names.

### Scope

Scrollable single-page data narrative where numbers are the protagonist. Atmosphere: information density Low → High (rhythm-controlled); visual rhythm strong alternation (different archetype per section); narrative arc Beginning → Middle → End.

Supported data shapes: time-series · proportions · paired metrics · ranking · grouped metrics · event sequence · peer catalog · comparison.

### Voice

Third-person observational. Use `we` only in attribution. Statements not CTAs: `Bookings closed at 142,300`. Eyebrows: uppercase mono `tracking-[0.16em]`. Titles: sentence case, no terminal period (except `impact` / `technical` allow ALL CAPS Hero title). Body: sentence case full sentences.

Numbers in copy: tabular figures, thousands separators, no decimal padding. Period strings: `·` middle dot (U+00B7) with single spaces.

## 11. Section Archetype Library

A section = archetype (what) + composition treatment (layout) + dominant move (eye-lead).

### Composition Treatments

| Treatment | Logic | Density |
|---|---|---|
| Full-bleed Monolith | One element fills frame, centered | spacious |
| Asymmetric Split | Two unequal columns (3:2 / 2:1) | medium |
| Stacked Band | Full-width bands stacked | medium–dense |
| Matrix Grid | Equal cells N×M, narratively bound | dense |
| Proportion Rail | Continuous parts-of-whole rail | medium |
| Offset Frame | Disrupts grid: crop/off-center/overflow | medium |
| Sequence Track | Stepped: index → title → note | medium–dense |
| Typographic Field | Type alone, no panels or chrome | spacious–medium |
| Annotation Rail | Main (3/4) + narrow rail (1/4) | medium |

Favored: Typographic Field (Hero), Matrix Grid (KPI Cluster), Stacked Band, Asymmetric Split.

### Dominant Moves

| Move | Class |
|---|---|
| Scale jump (focal ≥ 2 tiers larger) | steady |
| Single stroke (one line/accent) | steady |
| Path reveal (curve draws / rail fills) | steady |
| Crop / bleed | disruptive |
| Offset placement | disruptive |
| Column break | disruptive |

Leads with scale jump and single stroke. Disruptive ≤ 1 chapter per page.

### Archetypes

**Hero Monolith** — Opening anchor. Default treatment: Typographic Field. Alts: Asymmetric Split, Full-bleed.

**Time Series** — Values over time. Treatments: Stacked Band *(default)* · Asymmetric Split. Bare recharts `AreaChart`/`LineChart` in `<ResponsiveContainer>`.

**Proportion Field** — Parts-of-whole. Treatments: Proportion Rail *(default)* · Stacked Band. Donut/pie/ring forbidden. Horizontal `BarChart` + `<LabelList>` or shadcn `Progress`.

**Comparison** — Two metrics contrasted. Treatments: Asymmetric Split *(default)* · Stacked Band. Left/right same font-size; hierarchy from color — leading `--primary`, trailing `--foreground-3`.

**Ranking / List** — Items by magnitude. Stacked Band (≤ 5) · Matrix Grid (≥ 6). Scale jump on top-1. List typography — never recharts `BarChart` for ranking.

**Grouped Metric Cluster** — Parallel metrics, one claim. Matrix Grid 2×2/2×3: CSS `grid gap-1`, `bg-surface-l2 rounded-[var(--radius)] p-6 md:p-8`, no extra border/shadow.

**Sequence / Timeline** — Time-ordered events (not values). Sequence Track default. Horizontal Timeline alt (desktop): 3-5 col grid, primary-bordered circle dots. Mobile fallback (< md): Vertical Timeline, left-aligned, 1px `--border-strong` vertical rail.

**Peer Set / Catalog** — Same-kind peers. Matrix Grid default. Shadcn `Card` (border-0 shadow-none p-0).

**Quote Interstitial** — Narrative pause. Typographic Field. No icon, no brackets — quote unadorned, opening en-dash `—` `--primary` as lead-in. One sentence ≤ 28 words, Quote scale body weight — no italic, no left border.

**Outro Reverent** — End of report. Typographic Field. Closing claim Section Primary + terminal `Separator`. Optional — emit only with closing claim.

## 12. Composition

Default: Hero → evidence chapters → optional Outro. Section count follows data; stop before filler. Supports as many chapters as data evidence demands; density per `density` dial.

### Rhythm

1. **Density rotation** — adjacent differ (dense / medium / spacious); no two consecutive dense.
2. **Treatment variety** — no two consecutive same treatment or archetype.
3. **Bold-move budget** — disruptive ≤ ceil(N × 0.25).
4. **Break cadence** — ≥ 1 section uses Full-bleed, Offset, or Typographic Field. Hero + Outro satisfy.

### Rules

Ground consistent across chapters; vary rhythm through density, hairlines, accent position. Chapter markers `01` `02` `03`. ChapterStamp at most 3× when optional. Chapter opener: ChapterBanner + Separator every non-Hero chapter (one per chapter, no exceptions). Chapter divider for in-chapter rests, sparingly.

## 13. Section Anatomy

### 13.1 Hero Monolith

Focal: primary-value Display Number, display stack `font-medium`/Display weight, `--primary`, inline unit `--primary-hl`, animated count-up. Background: page-level `var(--background)` ground + hero shader per `hero_shader` dial (scoped to Hero section, viewport-paused).

Composition — Typographic Field: centered type-only field. No chart, no figure — claim-line title carries the section.

Hero brand marks: focal numeral, delta indicator, shader breath.

Anti-refs: don't set Hero on saturated brand-hue ground; don't use product photos; don't stack banners or KPI grids in Hero; don't pair brand accent with a second hot accent.

Primary-value selection: (1) rate/percentage → avg, (2) aggregate keyword → sum, (3) primary metric → max, (4) same → avg. If missing, omit Hero.

- **Loading**: skeleton replaces only data-dependent slots. Static section structure, Hero shader, chapter markers remain visible.
- **Empty**: section frame + centered "No data available" in `--foreground-3`.
- **Error**: frame + retry icon + "Failed to load" + retry button in `--foreground-2`.

## 16. Components Inventory

### Hero shader (per `hero_shader` dial)

Pass hex/rgb/hsl strings to paper-shaders `colors` and `colorBack` props — the shader engine does not parse CSS `oklch()`. CSS tokens with oklch() still apply on regular DOM elements.

| Engine | Props schema (no React snippet) | colors sampling | Numeric range |
|---|---|---|---|
| **mesh** (`MeshGradient`) | `colors: string[4-6]` · `distortion` · `swirl` · `grainMixer` · `speed` | 4-6 hex, L 0.85-0.97, max C 0.06, ΔL ≤ 0.10 across set | distortion 0.3-1.1 · swirl 0.2-0.8 · grainMixer 0.01-0.10 · speed 0.10-0.45 |
| **grain** (`GrainGradient`) | `colors: string[2-4]` · `softness` · `intensity` · `speed` | 2-4 base hex L 0.80-0.95 + optional accent point | softness 0.4-0.8 · intensity 0.06-0.15 · speed 0.10-0.30 |
| **dithering** (`Dithering`) | `type` · `shape` · `size` · `scale` · `colorFront` · `colorBack` · `speed` | colorFront L 0.55-0.75 neutral · colorBack L 0.92-0.97 | type `8x8`/`4x4` · shape `simplex`/`wave` · size 2-6 · scale 0.8-1.4 · speed 0.3-0.5 |
| **none** | n/a (static CSS dot-grid or line-grid fallback in Hero) | n/a | n/a |

Sampling rules: each numeric param INDEPENDENTLY sampled from row's range, 1 decimal. Never mix across engines. Never reuse same combination twice in a session.

Hero shader policy: 1 WebGL instance per page (Hero only). Pauses to `speed: 0` off-viewport, returns to row speed on re-enter. Shader `position:absolute inset:0`; overlay `position:relative z-1`. CSS fallback `backgroundColor=var(--background)`. NO foreground images in shader hero. Scope: hero ONLY.

### AnimateNumber

`motion-plus/react` AnimateNumber. Children must be pure numeric string. Use `parseDisplayValue()` to split Bitable formatted values (`"¥1,234,567"` → prefix `¥` + number `1234567` + suffix). Wrap in `inline-flex items-baseline gap-1 whitespace-nowrap`.

### Recharts

Bare recharts. Series colors from `var(--chart-1)` through `var(--chart-5)` directly. `isAnimationActive={false}` always. `--chart-1` latest period only, prior step to `--chart-3`–`--chart-5`. Grid `var(--border-strong)` horizontal only. Axis `var(--foreground-2)`, no tickLine/axisLine. Area flat `fillOpacity={0.2}`.

Recharts defaults render solid `#000` — every Bar, Tooltip, BarChart cursor must be explicitly token-styled. `<Bar fill>` required, `<Tooltip contentStyle>` required, BarChart `<Tooltip cursor>` required.

### ChapterBanner

Chapter index numeral + chapter title + `Separator` full-width below. Numeral and title typography per `font_family` dial. No SVG stamp / solid-fill / banner kicker unless `ceremonial` (then SealStamp circle 28-40px solid-fill `fill="var(--primary)"` with reverse numeral allowed).

### Separator

Radix-based (`@radix-ui/react-separator`), full-width 1px rule, no gradient, no dot, no fade. Shadcn `<Separator />` primitive.

### Tag / Pill

Sharp 0px corner always (regardless of `radius` dial). Thin border outline + sans body-weight label. Filled background only for `accent_strategy=mono`/`semantic` (uses `--primary-soft`); `silent` uses outline-only.

### Inline DeltaIndicator

No pill, no border, no background. Body-weight character + value. Up: `▲` `--primary`; down: `▼` `--foreground-2` (mono/silent) or `--destructive` (semantic).

### Tooltip contentStyle

Inline `contentStyle={{ background: "var(--surface-l1)", border: "1px solid var(--border-strong)", color: "var(--foreground)", borderRadius: <radius> }}` directly on `<Tooltip />`. No shadow.

### Inline number+unit

`inline-flex items-baseline gap-2 whitespace-nowrap`. Fits within card padding.

### Focal numeric font-size scaling

Apply length-based conditional className on Display Number from `displayNumber.length`: ≤ 7 char default scale (§3) / 8-11 char drop one tier / ≥ 12 char drop two tiers. Parent `min-w-0` AND child `whitespace-nowrap`. Don't rely on `min-w-0` alone or `clamp()` (sub-pixel jitter degrades AnimateNumber spring).

## 17. Component Constraints

Use top-level hooks, typed props, `motion/react`, `motion-plus/react`, numeric easing arrays, `aria-hidden` for decorative visuals, semantic labels for readable values, `isAnimationActive={false}` on Recharts, reduced-motion fallbacks for AnimateNumber + WebGL + off-screen continuous motion.

Forbidden dial combinations (HARD):
- `impact` + `playful` radius — visual whiplash
- `editorial` + `dense` density — undermines reading rhythm
- `ceremonial` + `semantic` accent — color budget collapse
- `technical` + `mesh` shader — readability conflict on data sections

Reject the page if any combination above is requested. Negotiate toward nearest legal pair before rendering.
