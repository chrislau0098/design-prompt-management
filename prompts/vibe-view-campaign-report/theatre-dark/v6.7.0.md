## 1. Brand & Style

Mood: **Solemn · Restrained · Textured · Uplifting**

Proposition: A dark theatrical stage where numbers perform — quiet luxury via single accent, depth via linework, light, and motion.

Color rules:
- Key numbers use `--primary`. Brighter or deeper orange values appear only in chart colors or restrained light.
- Complex charts use the ordered Primary orange ramp: chart-1 starts at `--primary`, then steps through darker same-hue orange values. No green, cyan, rainbow, or library-default categorical palette.
- Single-series charts use chart-1 for the active line and chart-5 at low opacity for baselines, grids, and historical context.
- Chart hover cursor, active bar background, and tooltip highlight area use `--chart-hover`, one dark step above the black background. Never use default white, light gray, or high-contrast hover bands.
- Depth via linework, spacing, typography, and restrained light, not shadow-heavy gray cards.
- No `#000000`. No `#FFFFFF`. Use defined tokens only.
- 60-30-10: 60% background, 30% surface+text, 10% accent.

Brand hue: `--brand-hue` is the single configurable knob for the accent system. `--primary`, `--primary-hl`, `--primary-glow`, and `--chart-2` through `--chart-5` each keep a fixed lightness and chroma and take only their hue from `--brand-hue`; `--chart-1` mirrors `--primary`. Changing `--brand-hue` rotates the whole accent system at once and preserves the lightness and chroma relationships that keep the ramp readable. The neutral base — backgrounds, surfaces, foregrounds, borders, `--chart-hover`, `--quote-bg`, `--outro-bg`, `--glow-ink` — stays fixed and does not track `--brand-hue`. Only `--brand-hue` is intended to be reconfigured; the lightness and chroma values are the fixed style recipe.

## 4. Spacing & Layout

Base unit: Tailwind spacing `2` (8px). Scale: `1` `2` `3` `4` `6` `8` `12` `16` `24` (Tailwind spacing units; `1` = 4px).

Section padding: `py-24 px-6` (mobile) → `py-40 px-16` (desktop).
Container: `max-w-5xl` centered. `gap-2` grid. `items-baseline` for mixed text. `min-w-0` on nested flex/grid children.

Overflow adaptation: long numbers and long labels must not overlap adjacent elements or break out of the section frame. Truncate, wrap, or scale text to fit; size every layout against the longest plausible value, not a short sample. Test focal numbers and labels at their maximum realistic length.

Density: one data story per viewport height.

Gaps: `gap-1` tight (indicator internals) · `gap-3` standard (label+number) · `gap-6` loose (intra-section) · section-level via padding.

## 5. Material

Surface: **elevated** — depth via border + near-black surface contrast, not shadow.

Borders: Whisper `1px solid oklch(1 0 0 / 0.06)` · Strong `1px solid oklch(1 0 0 / 0.12)`.

Double-Bezel: outer `p-1.5 ring-1 ring-white/5 rounded-[6px]` → inner `rounded-[4px] bg-surface-l2 p-6 md:p-8`.

Shadow: panels `inset 0 1px 0 oklch(1 0 0 / 0.04), 0 0 28px oklch(0.08 0.012 260 / 0.38)`. Glow is a diffused background spotlight only, not a card edge or text effect.

Radius: `rounded-[2px]` · `rounded-[4px]` · `rounded-[6px]` for cards, panels, charts, tables, frames, and inline indicators. No `rounded-xl`, `rounded-2xl`, `rounded-3xl`, pill radius, blob card, or fully rounded card shape.

Dividers: accent `linear-gradient(to right, transparent, oklch(0.720 0.160 var(--brand-hue) / 0.3), transparent) h-px`; content `oklch(1 0 0 / 0.08) h-px`.

Panel discipline: panels frame charts, dense tables, or grouped evidence only. Use small radii and thin borders. Do not place every section inside the same rounded dark surface. Each archetype carries one distinct material or spatial logic such as stage floor, annotation rail, ticket rows, scale marks, path field, or open typographic field.

## 6. Motion

Engines: `motion/react` · `motion-plus/react` (AnimateNumber) · `@paper-design/shaders-react` (MeshGradient).

```ts
const EASE = {
  out:    [0.16, 1, 0.3, 1],
  inOut:  [0.83, 0, 0.17, 1],
  snap:   [0.2, 0, 0, 1],
  spring: [0.45, 0, 0.55, 1],
};
```

| Category | Duration | Easing |
|----------|----------|--------|
| Hover | 180ms | out |
| Button press | 120ms | snap |
| Element entrance | 600-1000ms | out |
| Number rolling | 1.0-2.4s | spring physics, no visible bounce |
| Curve pathLength | 2.4-3.2s | out |
| Spotlight drift | 7s/cycle | inOut, infinite |
| WebGL | continuous | speed: 0.5 |

Entrance: Hero uses `animate=` with orchestrated delays. Other sections use `whileInView`, `once: true`, `margin: "-20%"`, and only animate the focal element. Section shell, headings, and readable text render visible before in-view animation; do not hide the whole section wrapper.

**whileInView is mandatory for scroll-triggered entrance — NEVER use useInView + animate.**
`motion/react` provides `whileInView` and `viewport` props that handle intersection observation internally. Do not manually create refs and `useInView` hooks to conditionally set `animate`.

```tsx
// ✅ CORRECT — whileInView + viewport (built-in, declarative)
<motion.div
  initial={{ opacity: 0, x: -20 }}
  whileInView={{ opacity: 1, x: 0 }}
  viewport={{ once: true, margin: "-20%" }}
  transition={{ duration: 0.7, ease: EASE.out, delay: 0.2 }}
>
```

Motion idea per viewport: one focal motion idea only. Hero staged reveal; Time Series path/fill draws; Proportion rail fills; Ranking rows cascade; Quote crossfades; Outro settles. Do not apply the same `y + opacity` reveal to every section.

AnimateNumber: roll triggers only on child value change — always use {displayValue || 0} (see §17). Only the Hero metric and one focal metric per section may roll; supporting numbers render static. Motion: spring, no bounce. Unit text stays outside the animated number and is never duplicated.

SVG: `pathLength: 0→1` draw-in. Breathing via `d` morph. No `<circle>` inside `preserveAspectRatio="none"` — use HTML border-radius.

`prefers-reduced-motion`:
- CSS: `animation-duration: 0.01ms !important`
- Motion: section opacity crossfade only; no translate, scale, stagger, or path draw.
- WebGL: `speed: 0`
- AnimateNumber: plain final text

Data-driven value invariant: numerical animation primitives (AnimateNumber, useSpring numerical target, motion value transforms) need a meaningful value at each frame. When the data source returns null, undefined, or the query yields no rows, render the section's empty state (per §15) instead of attaching a broken animation.

Continuous motion: WebGL, SVG loops, CSS spotlight drift, and repeated background motion run only while their section is in view. Off-screen continuous motion pauses.

## 9. Do's and Don'ts

Do:
- Single burnt-orange brand accent, with a separate ordered chart ramp
- Depth through linework and restrained light
- Primary numbers as visual protagonist — large, upward, rolling only when focal
- Warm ivory text on cool-toned backgrounds
- One structural visual decision per viewport beyond color: crop, offset, scale, path, rail, field, stage plane, or typographic lockup

- **Don't** use plastic orange `#FFA500` — use `--primary` for key accents
- **Don't** use neon/cyberpunk/red-gold palettes — use the chart-1 through chart-5 orange ramp only
- **Don't** create 3-column equal grids — asymmetric or single-column
- **Don't** use large-radius cards, `rounded-xl`, `rounded-2xl`, `rounded-3xl`, blob cards, pill cards, or soft app-store tiles — cards and panels use `rounded-[2px]` through `rounded-[6px]`
- **Don't** nest cards beyond Double-Bezel — 2 layers max
- **Don't** use frosted glass, `backdrop-blur`, or rim lighting — depth comes from linework, spacing, and a single radial spotlight, not from blur effects
- **Don't** use the same small rounded dark panel as the default material for every section — vary material logic by archetype
- **Don't** use Inter/serif fonts — Geist + Noto Sans SC
- **Don't** apply weight 600 globally — restricted to indicator values and marker numbers
- **Don't** fade whole sections with opacity-only — use a semantic focal motion such as path draw, proportion fill, row cascade, or subtle transform
- **Don't** tween numbers as single value — per-digit spring
- **Don't** expose rolling-number internals such as repeated `0123456789` stacks — fall back to the final static number
- **Don't** animate CSS layout properties (`width`, `height`, `padding`, `margin`, `top`, `left`, `right`, `bottom`, `font-size`, `gap`, `grid-template-*`) — animate `transform` and `opacity`; use FLIP only for unavoidable layout transitions
- **Don't** use ease strings — cubic-bezier arrays only
- **Don't** use `h-screen` — use `min-h-dvh`
- **Don't** use `useInView()` + conditional `animate={}` for entrance animations — use `whileInView` + `viewport` props. `useInView` is ONLY for controlling continuous motion (shader speed, SVG loop playback) that must pause off-screen.

## 10. Pattern Overview

### Scenario Mindset

This page is a story told in data, not a dashboard — every section is a chapter, every chart is evidence for a claim.
The narrative arc runs across the whole page: opening hook → supporting evidence → closing impact. Each section advances exactly one beat of the arc.
Each section carries one focal claim and exactly one supporting visual (chart, ranking, or quote). Parallel KPI tiles, side-by-side metric grids, and three competing focal numbers belong to a dashboard, not a campaign report.
A successful page lets the reader leave with three things: the headline number, the why behind it, the so-what of it.
Archetype names are internal planning labels only. Visible eyebrows, captions, and labels come from the topic, period, data role, or business meaning, not from section archetype names.

### Scope

Scope: scrollable single-page data narrative where numbers are the protagonist.

Atmosphere:
- Information density: Low → High (rhythm-controlled)
- Visual rhythm: Strong alternation (different archetype per section)
- Narrative arc: Beginning → Middle → End

Supported data shapes: time-series · proportions · paired metrics · ranking · event catalog · comparison.

### Voice & Copy

The page's copy reads like a curator's wall text — terse, third-person, observational. 

- Voice: third-person observational. Use `we` only in attribution; never address the reader as `you`.
- Statements, not calls to action: `Bookings closed at 142,300`, not `We booked 142,300!` — a campaign report is a read-only artifact.
- Eyebrows: uppercase, mono, `tracking-[0.14em]`. Titles: sentence case, no terminal period. Body: sentence case, full sentences, terminal punctuation.
- Numbers in copy: tabular figures, thousands separators, no decimal padding.
- Period strings use a `·` middle dot (U+00B7) with single spaces around it.

## 11. Section Archetype Library

### Hero Monolith
Trigger: Opening anchor metric. Visual: full-viewport number composed with crop, offset, light beam, or stage plane. Centered placement is allowed only when the number is integrated with the shader or path field. Slots: eyebrow · metric-label · primary-value · unit-text · delta-indicator · subtitle. Background: full-bleed shader.

### Dominant + Sidecar
Trigger: Primary metric with supporting evidence. Visual: asymmetric 3fr/2fr. Slots: primary-visual · sidecar-evidence · label · annotation. Sidecar is an evidence panel, not a KPI tile stack.

### Time Series Chart
Trigger: Ordered points over time dimension. Visual: full-width area/line. Slots: title · time-axis · value-axis · series (1-3) · legend · callout.

### Proportion Field
Trigger: Parts-of-whole as percentages. Visual: stacked rail, horizontal proportion band, ranked distribution, or theatre-seat field. Slots: proportion-visual · focal-value · integrated labels (2-5) · note. Donut charts are not the default visual for this archetype.

### Comparison (Paired Metrics)
Trigger: Two metrics contrasted side by side. Visual: asymmetric split with divider. Slots: left-value · left-label · right-value · right-label · divider · delta.

### Ranking / List
Trigger: Items ordered by magnitude. Visual: vertical row stack, top item emphasized. Slots: rank · label · value · delta · highlight (top 1-3).

### Quote Interstitial
Trigger: Narrative pause between data sections. Visual: dark surface, centered text, decorative quote mark. Slots: mark · text · attribution · surface. Quote text is one sentence, 28 words or fewer.

### Outro Reverent
Trigger: End of report. Visual: centered closing statement; reverent tone, no interactive elements. Slots: title · subtitle · flourish · statistical caveats (period, source, audit note where relevant). Background: `--outro-bg`.

## 12. Composition

Default sequence: Hero Monolith → data-supported evidence chapters → optional Outro Reverent.

Adjacency rule: No two consecutive sections use the same archetype.

Background rhythm: `--background` and `--surface-l1` stay near-black; vary rhythm with composition, linework, and light placement instead of deep-gray section bands.

Skip rule: choose sections by data shape and business relevance. Omit archetypes whose data is absent. Do not pad with empty sections.

Chapter markers: sequential 01, 02, 03... when useful. Markers are optional and vary by composition: side note, tick mark, rail label, divider number, or small stamp. Do not repeat the same circular stamp treatment across every chapter.

Section count: use as many sections as the data and business story support. Sparse datasets may produce Hero + 1-2 evidence chapters. Rich datasets may extend further when each chapter carries a distinct claim. Stop before a section becomes filler.

## 13. Section Anatomy

### Hero Monolith
Focal: primary-value — the numeric value itself, rendered as the single largest element in the Hero at Display Number scale (`text-[80px]` → `text-[128px]` → `text-[192px]`, per §3), `--primary`, and animated with AnimateNumber (the `{displayValue || 0}` roll, see §17). Secondary: delta-indicator, subtitle. Tertiary: eyebrow, metric-label, unit-text. The metric-label (the metric's name, e.g. a column display name like `总成交额` / `Total GMV`) and the unit-text (`万` / `亿` / `%`) are supporting elements — never rendered at Display Number or Section scale, never larger than the primary-value. BG: full-bleed shader.

Hero background field: near-black theatre ink with restrained orange light. MeshGradient occupies the full viewport; dark vignette overlays stay below 0.35 alpha and never cover the center of the shader. Do not use the chart ramp, blue, purple, or rainbow transitions in the Hero background. The Hero background is the shader only — do not place raster images or photographs in the Hero unless the user explicitly requests imagery.

Hero composition: the primary number interacts with at least one structural element: cropped edge, spotlight cone, stage horizon, offset frame, or data path. Avoid the plain centered big-number hero made only from eyebrow, number, pill badge, and paragraph.

Primary-value selection — pick exactly one numeric value to headline the campaign.

Selection priority (resolve by field name pattern; stop at the first match):

1. **Rate/percentage field**: A field whose display name contains a percent or rate indicator (`达成率`, `完成率`, `达成%`, `achievement %`, `completion rate`, or any explicit percent/rate keyword). Show the average of this field across all records.
2. **Explicit aggregate field**: A field whose display name is an aggregate keyword (`总计`, `总数`, `合计`, `total`, `aggregate`). Show its sum.
3. **Primary metric field (max)**: Otherwise, identify the primary metric field by name semantics — the field most likely to headline a campaign report based on its name (e.g. `得分`, `销售额`, `revenue`, `GMV`; exclude fields whose names carry percent/rate suffixes). Show the maximum value of this field.
4. **Primary metric field (avg)**: Same field as rule 3, but show the average instead.

Display the selected numeric value directly. Preserve units and percent signs already present in the source value; do not append a second `%` based on field name or rate semantics. If the selected value is missing or null, omit the Hero Monolith section entirely (per §15 empty-state rule) — do not render a degraded Hero with placeholder text.

Eyebrow slot format pattern: `{topic} · {period}` (e.g. `Q1 SALES PERFORMANCE · 2026`). Always emit the actual period from data context; if period is not available in data, omit the period segment entirely — do not emit placeholder strings like "202X" or "YYYY".

Non-Hero sections follow §11 slot order: first slot is focal, second slot is supporting evidence, labels and notes are tertiary.

## 16. Do's and Don'ts

Do:
- Alternate archetypes between sections
- Keep backgrounds near-black; vary rhythm through composition and linework
- One focal element per section
- Skip data-absent sections
- Use chapter markers only where they support navigation or rhythm
- Use visible labels from topic, period, metric role, or business meaning

- **Don't** repeat the same archetype consecutively — breaks rhythm
- **Don't** show archetype names such as `Dominant + Sidecar`, `Proportion Field`, `Ranking / List`, or `Outro Reverent` in visible UI — they are internal planning labels
- **Don't** use equal 3-column grids — data narratives need asymmetry
- **Don't** use a plain centered big-number Hero with pill indicator as the whole composition — compose the number with crop, path, light, or stage structure
- **Don't** fix section heights — let content determine with min-height
- **Don't** show multiple primary numbers in one section — dilutes focus
- **Don't** separate chart legends from their chart — same visual group
- **Don't** use donut, pie, or ring charts of any kind, or detached dot legends — proportion is always read as a continuous rail or band, with segments tinted in chart-ramp order
- **Don't** use sidecar KPI tile stacks — use evidence panels, annotations, thresholds, compact tables, or one support metric
- **Don't** repeat identical circular chapter markers across all sections — vary or omit markers
- **Don't** apply identical `y + opacity` section reveals everywhere — each archetype has one semantic motion idea
- **Don't** hide whole section wrappers before they enter view — headings and readable text remain visible for long-page capture
- **Don't** render white or light-colored overlays, masks, scrims, or loading skeletons — every overlay and skeleton uses dark surface or ink tokens; a white layer never appears in a dark-theme report
- **Don't** show more than 5 ranking items without truncation
- **Don't** allow horizontal scroll — stack on mobile
- **Don't** use emoji anywhere — not in copy, labels, indicators, captions, or bullets
- **Don't** add CTA buttons of any kind — no "view full data" / "view more" / "view detail" / "查看完整", no action buttons, no links styled as buttons. Campaign reports are read-only narrative artifacts. Reject dashboard verbs (track, monitor, drill down, explore), marketing verbs (unlock, discover, supercharge, transform), and second-person imperatives.
- **Don't** force an outro when the data has no closing claim — end on the strongest supported evidence section

## 17. Components Inventory

### Pre-imported

**MeshGradient** (@paper-design/shaders-react) — WebGL mesh gradient for full-bleed shader backgrounds. Usage: ambient cinematic background tied to a section's visual identity; pair with a low-opacity overlay to keep foreground content legible.
```tsx
import { MeshGradient } from "@paper-design/shaders-react";

<MeshGradient
  colors={["#0A0B0D", "#1A0E08", "#D75F28", "#3D1A0A", "#0A0B0D"]}
  speed={isShaderActive ? 0.5 : 0} distortion={0.8} swirl={0.3} grainOverlay={0.12}
  style={{ width: "100%", height: "100%", opacity: 0.52 }}
/>
```
API critical notes: `colors` is a 4–7 element hex string array — hex literals are the only place hex is permitted in this style. Set `isShaderActive = inView && !prefersReducedMotion` from the section visibility state and `useReducedMotion()` from `motion/react`. Hero shader overlays are subtle readability layers, not black covers; total dark overlay opacity stays at or below 0.35.

**AnimateNumber** (motion-plus/react) — Per-digit scroll. `{number || 0}` triggers roll. Children must be a **pure numeric string** (no commas, no symbols). Bitable formatted values like `"¥1,234,567.00"` or `"85%"` will NaN — use `parseDisplayValue()` to split first. 

```tsx
import { AnimateNumber } from "motion-plus/react";

// Split Bitable formatted value → prefix / pure number / suffix
function parseDisplayValue(value: string | undefined) {
  if (!value) return { prefix: "", number: "0", suffix: "" };
  const match = value.match(/^([^\d\-]*?)(-?[\d,]+\.?\d*)(.*)$/);
  if (!match) return { prefix: "", number: "0", suffix: "" };
  return {
    prefix: (match[1] ?? "").trim(),
    number: match[2].replace(/,/g, ""),  // strip commas
    suffix: (match[3] ?? "").trim(),
  };
}

// Usage: "¥1,234,567.00" → prefix="¥", number="1234567.00", suffix=""
//        "85%" → prefix="", number="85", suffix="%"
const { prefix, number, suffix } = parseDisplayValue(row["sum(fldRevenue)"]?.value);
<span className="inline-flex items-baseline gap-1 whitespace-nowrap">
  {prefix && <span style={{ color: "var(--primary-hl)" }}>{prefix}</span>}
  <AnimateNumber
    style={{ color: "var(--primary)" }}
    transition={{ type: "spring", duration: 2.0, bounce: 0 }}
  >
    {number || 0}
  </AnimateNumber>
  {suffix && <span style={{ color: "var(--primary-hl)" }}>{suffix}</span>}
</span>
```


**AreaChart** (recharts) — Filled area chart for time-series or growth visualization. Usage: render a continuous numeric series indexed by a categorical axis (period, date, segment).
```tsx
import { AreaChart, Area, XAxis, YAxis, Tooltip, ResponsiveContainer } from "recharts";

<ResponsiveContainer width="100%" height={400}>
  <AreaChart data={series} margin={{ top: 24, right: 24, bottom: 24, left: 24 }}>
    <XAxis dataKey="period" stroke="var(--foreground-2)" />
    <YAxis stroke="var(--foreground-2)" />
    <Tooltip cursor={{ fill: "var(--chart-hover)" }} />
    <Area type="monotone" dataKey="value" stroke="var(--chart-1)" fill="var(--chart-1)" fillOpacity={0.2} isAnimationActive={false} />
  </AreaChart>
</ResponsiveContainer>
```
API critical notes: always set `isAnimationActive={false}` — recharts' default animation conflicts with motion entrance. Use OKLCH `var(--…)` color strings on `stroke` / `fill`, not Tailwind palette classes. Tooltip cursor, active bar, and hover highlight fill use `var(--chart-hover)`, never default white or light gray. Axis and tick text below `text-[14px]` use `--foreground-2`; `--foreground-3` is for gridlines and non-essential marks. This color discipline applies to every recharts chart type, not only AreaChart: recharts defaults to white or light-gray fills, strokes, and tooltips, which never match this style. Pass explicit `var(--chart-1..5)` colors on every series and `var(--chart-hover)` on every Tooltip cursor and active state.

**DeltaIndicator** — Compact change indicator with directional arrow. Usage: any place a metric needs to communicate "how much it changed" alongside the absolute value.
```tsx
function DeltaIndicator({ value, direction, label }: { value: string; direction: "up" | "down"; label?: string }) {
  const isUp = direction === "up";
  const Arrow = isUp ? "↑" : "↓";
  // Up uses the orange accent; down stays neutral — the accent is reserved for positive focal signal.
  const tone = isUp
    ? { background: "oklch(0.650 0.175 var(--brand-hue) / 0.05)", border: "1px solid oklch(0.650 0.175 var(--brand-hue) / 0.4)", color: "var(--primary)" }
    : { background: "oklch(0.500 0.020 248 / 0.05)", border: "1px solid oklch(0.620 0.012 139 / 0.4)", color: "var(--foreground-2)" };
  return (
    <span className="inline-flex items-center gap-1 px-2.5 py-1 rounded-[4px] text-[14px] font-medium" style={tone}>
      <span aria-hidden>{Arrow}</span><span>{value}</span>{label ? <span className="opacity-70">{label}</span> : null}
    </span>
  );
}
```

**SpotlightGradient** — Radial halo overlay creating directional ambient light. Usage: layer behind a section's main content for a subtle directional glow; one per section max.
```tsx
function SpotlightGradient({ position, intensity = 0.7 }: { position: "top-center" | "top-right" | "bottom-center"; intensity?: number }) {
  const map = { "top-center": "50% 0%", "top-right": "80% 10%", "bottom-center": "50% 100%" } as const;
  const bg = `radial-gradient(ellipse at ${map[position]}, oklch(0.720 0.160 var(--brand-hue) / ${intensity * 0.25}), transparent 60%)`;
  return <div className="absolute inset-0 pointer-events-none" style={{ background: bg }} aria-hidden />;
}
```

Use top-level hooks, typed props, `motion/react`, `motion-plus/react`, numeric easing arrays, `aria-hidden` for decorative visuals, semantic labels for readable values, `isAnimationActive={false}` on Recharts, and reduced-motion fallbacks for AnimateNumber, WebGL, spotlight, and off-screen continuous motion.
