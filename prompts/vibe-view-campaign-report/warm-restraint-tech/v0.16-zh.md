## 1. 品牌与风格

情绪：**温暖 · 笃定 · 品牌前置 · 明亮**

定位：这是一个象牙色的 campaign report。暖橙色余烬光从 Hero 向外辐射；章节开场由发丝线、等宽余烬色 kicker 和主张句标题构成；大号人文无衬线数字以余烬色承载每一个论断；暖中性色单位和变化箭头标记方向。戏剧性来自暖光场、Hero 下方呼吸流动的暖颗粒 shader、章节发丝线节奏，以及始终保持 medium 字重的笃定无衬线排版。

颜色规则：
- 焦点数字使用 `--primary`（余烬色，L 0.72 C 0.16）。单位、单位后缀、百分号、delta 箭头和 delta 数值使用 `--primary-hl`（同色相，更亮，L 0.78 C 0.14）。
- 图表：使用 chart-1 到 chart-5 的有序余烬色阶。最新周期使用 chart-1 余烬色；此前周期递进到 chart-3 到 chart-5 的暖中性色。不要使用绿色、蓝色、组件库默认色或 Tailwind 调色板。hover、active-bar、tooltip 使用 `--chart-hover`。
- 深度来自 Hero 暖颗粒 shader、章节发丝线节奏、排版尺度和余烬强调色，而不是重阴影卡片。边框要极薄低声；surface 叠层最多只差一个 L 阶。
- 每个 viewport 内余烬强调色占 8-15%。只保留给：焦点数字、chart-1 最新周期、Hero shader 呼吸、章节序号数字、每个 section 中一个结构性强调点。
- 不使用 `#000000`。不使用 `#FFFFFF`。只使用 token。60-25-15：60% 石灰灰底、25% 暖墨正文和发丝线、15% 余烬强调。

品牌色相：`--brand-hue` 是唯一的强调色旋钮。强调色 token 从它派生；中性色 token（background、surfaces、foregrounds、borders）固定在 hue 80 的低彩度石灰灰，以较冷静的底色最大化余烬色对比。

## 4. 间距与布局

基础单位：8px。尺度：`1` `2` `3` `4` `6` `8` `12` `16` `24` `32`。Section：移动端 `py-32 px-6` → 桌面端 `py-56 px-20`。Container：段落驱动用 `max-w-3xl`；KPI/chart 用 `max-w-5xl`。Grid：`gap-2`、`items-baseline`、`min-w-0`。

长滚动节奏：章节纵向堆叠，由发丝线 + `· · ·` 装饰分隔。高度由内容决定，`min-h-[80vh]` 作为下限。溢出时：截断、换行，或按最长合理值缩放。

密度：每个 viewport 一个观察点。Gaps：`gap-1` 紧凑 · `gap-3` label+number · `gap-8` paragraph→KPI · `gap-12` KPI→chart。

圆角：pill/tag：full。锐利面板（table/chart）：`rounded-[0px]`-`rounded-[4px]`。卡片 chrome（cluster/commitments）：`rounded-[16px]`。

KPI row：4-6 个 cell，垂直发丝线列规则，Display Number + unit + caption。`px-6 py-4`；第一个 `pl-0`。`md:` 以下堆叠并改用水平发丝线。

## 5. 材质

Surface：石灰纸底来自双层 shader：页面级 `<StaticMeshGradient>`（静态，speed 0，fixed inset）生成石灰灰氛围；Hero 锚点 `<GrainGradient>`（wave，speed 1.1，离开 viewport 暂停）生成暖颗粒焦点场。面板通过发丝线 + 单阶 L 差抬起，绝不使用阴影堆叠或 backdrop-blur。

边框：Whisper `1px solid oklch(0.220 0.005 80 / 0.09)` · Strong `oklch(0.220 0.005 80 / 0.18)`。卡片无阴影。

Shader 策略：每页 ≤ 2 个 WebGL。Hero `GrainGradient` 离开 viewport 后暂停到 `speed: 0`，重新进入时恢复到 `speed: 1.1`。

Ember wash：`--ember-wash` 约 14% alpha 的 radial gradient，只用于标记 Hero 焦点数值和 Outro signature。它位于 shader 之上、文字之下。

章节开场：`ChapterBanner` — `--border-strong` 发丝线 + 等宽余烬色 kicker + `--foreground` sans medium 章节标题。左对齐，不使用渐变条带。

章节分隔：1px `--border` + `· · ·`，`--foreground-3` Mono，`text-[13px]`，`tracking-[0.8em]`。只用于章内休止。

面板纪律：chart frame 用 `rounded-[2px]`，card chrome 用 `rounded-[16px]`。每种 archetype 只采用一种材质逻辑。

## 6. 动效

引擎：`motion/react` · `motion-plus/react` (AnimateNumber) · `@paper-design/shaders-react` (StaticMeshGradient, GrainGradient)。

```ts
const EASE = {
  out: [0.18, 0.85, 0.22, 1], inOut: [0.7, 0.05, 0.2, 1],
  snap: [0.15, 0, 0.05, 1], spring: [0.42, 0, 0.3, 1],
};
```

| 类别 | 时长 | Easing |
|----------|----------|--------|
| Hover | 200ms | out |
| Button press | 120ms | snap |
| Element entrance | 600-1000ms, y: 32-36px | out |
| Number rolling | 1.6-2.2s | spring, no bounce |
| Curve pathLength | 2.4-3.0s | out |
| Signature stroke | 1.8s | out, one-shot |
| WebGL ground | static | speed: 0 |
| WebGL Hero | animated, viewport-paused | speed: 1.1 |

入场：Hero 使用 `animate=` 并设置 delay。其他元素使用 `whileInView`，并配置 viewport 为 `{{ once: true, margin: "0px 0px -10% 0px" }}`。必须使用 `once: true`，防止滚出屏幕后重置为初始隐藏状态；负 bottom margin 会在元素完全进入 viewport 之前预触发动画，避免快速滚动时跳过触发。Section shell、正文段落、chart wrapper 和 prose 首屏直接可见，不包动画 wrapper。

**整页中每一个 `whileInView` 都必须配套 `viewport={{ once: true, margin: "0px 0px -10% 0px" }}`** — 没有例外。缺少 `once: true` 时，元素滚出后会重置为 initial（opacity 0 / scaleX 0）并消失。这适用于 ChapterBanner、OutroSignature、Hero text rows、KPI cells，以及任何自定义 `motion.*` 元素。

```tsx
<motion.div initial={{ opacity: 0, y: 34 }} whileInView={{ opacity: 1, y: 0 }}
  viewport={{ once: true, margin: "0px 0px -10% 0px" }} transition={{ duration: 0.8, ease: EASE.out }} />
```

Stagger：`staggerChildren: 0.08` from `"first"`。移动端降到 `0.06`。

每个 viewport 的动效：只允许一个焦点动效。Hero staged reveal → Time Series area draw → Proportion rail fill → Ranking cascade → Quote crossfade → Outro signature。按 archetype 变化。

### 章节 reveal 触发器

```tsx
function useChapterReveal(margin = "-20%") {
  const ref = useRef<HTMLDivElement>(null);
  const inView = useInView(ref, { once: true, margin });
  const [revealed, setRevealed] = useState(false);
  useEffect(() => { if (inView) setRevealed(true); }, [inView]);
  return { ref, revealed };
}
```

把 `revealed ? data : zeros` 传入 AnimateNumber。Hero 使用 `margin: "0%"`。

### AnimateNumber 作用范围

包裹**每一个关键数字**：Hero primary、section focal claim、Comparison left/right、Ranking top-1、Cluster cell headlines。不要包裹 labels、ordinals、dates、axis values。每个 section 最多 3 个。`AnimateNumber` 只接受纯数字字符串 — 始终使用 `parseDisplayValue()`（§17）从 Bitable 格式化值中提取数字。

SVG：`pathLength: 0→1` draw-in。不要做 `d` morph。

`prefers-reduced-motion`：`animation-duration: 0.01ms !important`；只保留 opacity crossfade；WebGL `speed: 0`；AnimateNumber 改为纯文本。

数据驱动不变量：null/undefined → 渲染 empty state（§15），而不是破损动画。

连续动效：Hero `GrainGradient` 在 viewport 内 speed 1.1，离开后 0。`StaticMeshGradient` speed 0（静态）。SVG strokes one-shot。不要无限呼吸，不要 scroll-linked transforms。

## 9. Do's and Don'ts

Do：
- viewport 中 60% 是石灰灰底，余烬色占 8-15%，其余为暖墨正文。每章都用 `ChapterBanner` 发丝线 + kicker + 主张句标题开场。
- 焦点数字使用 `--primary` 余烬色；单位/百分号/delta 使用 `--primary-hl`，内联并基线对齐。Hero 以笃定的 sans medium 标题 + 段落副标题引导。
- 使用单一余烬色 chart ramp chart-1-5。最新周期使用余烬色；更早周期递进到 chart-3-5。
- 除颜色外，每个 viewport 最多一个结构性视觉决策。

- **Don't** 用 `--foreground` 渲染焦点数字 — 数字使用 `--primary`，暖墨色留给正文。
- **Don't** 使用冷色、蓝色、青色、紫色或非余烬强调色。不要重阴影、毛玻璃、`backdrop-blur`、rim lighting、card-edge glow 或 text glow。
- **Don't** 使用 `rounded-xl`/`rounded-2xl`/`rounded-3xl`/blob cards。锐利面板用 `rounded-[0px]`-`rounded-[4px]`；card chrome 用 `rounded-[16px]`。
- **Don't** 嵌套超过一层面板，也不要用页面级容器包裹 section。
- **Don't** 使用 Inter、Roboto、Space Grotesk、Plus Jakarta、MiSans 或过度使用的字体；CJK 首选 Noto Sans SC，Display Number 使用 Geist Variable，meta 使用 Geist Mono。
- **Don't** 使用 serif 字体或 italic 姿态。强调只来自尺度和颜色。
- **Don't** 使用超过 500 的字重。不要 `font-semibold`、`font-bold`、`font-extrabold`、`font-black`。
- **Don't** 在每章重复同一种 panel material。按 archetype 变化。
- **Don't** 对整个 section 做 opacity-only fade、重复同样的 `y + opacity` reveal，或动画 CSS layout 属性。只动画 `transform` 和 `opacity`。
- **Don't** 把数字当作单个值 tween，或重复 unit/percent；必须 per-digit spring。
- **Don't** 使用 ease 字符串；使用 cubic-bezier 数组。用 `min-h-dvh`，不要 `h-screen`。
- **Don't** 渲染低于 `text-[10px]` 的文本；必须阅读的信息使用 `text-[14px]+`。
- **Don't** 给每个数字都包 AnimateNumber — 只留给关键论断数字。Labels、ordinals、dates、axis values 直接渲染。
- **Don't** 使用没有 `viewport={{ once: true, margin: "0px 0px -10% 0px" }}` 的 `whileInView` — 省略 `once: true` 会导致元素滚出时重置为 initial state（opacity 0 / scaleX 0）并消失。页面中每个带 `whileInView` 的 `motion.*` 元素都必须包含完整 `viewport` prop。
- **Don't** 用 `useInView` + conditional `animate` 做入场；使用 `whileInView` + `viewport`。`useInView` 只保留给 Hero shader pause 和 chapter-reveal trigger（§6）。
- **Don't** 用 `useScroll`/`useTransform`/`scrollYProgress` 做 Hero exit 或 scroll-linked parallax。
- **Don't** 使用 ScrambleText、Typewriter、Ticker 或 character-level reveal。
- **Don't** 为 delta-down 或 error 引入第二个热强调色。暖中性墨色承载这些状态。
- **Don't** 让 bar chart bars 从 0 升起 — bars 静态渲染；highlighted bar 只做一次 `clip-path` reveal。
- **Don't** 随读者滚动对段落做 reveal。Prose 首屏直接可见。
- **Don't** 给章节 `<section>` 容器、chart wrappers、KPI grids、body paragraphs 或整页内容块包 `motion.div` 并设置 `initial={{ opacity: 0 }}` + `whileInView`。这些容器必须首屏可见。只有**细粒度装饰性入场元素**（Hero text rows、individual KPI cell content、ChapterBanner hairline+title、OutroSignature flourishes）可以用 `motion + whileInView + initial.opacity: 0`。Chapter shells、charts、lists 和 prose 都是内容，必须不包动画 wrapper 直接可见。过度包裹 motion 会在快速滚动且 `whileInView` 跳过触发时导致内容消失。

## 10. 模式概览

### 场景心智

这个页面是用数据讲述的故事，不是 dashboard — 每个 section 是一个章节，每个 chart 是一个论断的证据。
叙事弧贯穿整页：开场 hook → 支撑证据 → 收束影响。每个 section 只推进弧线中的一个节拍。
每个 section 承载一个焦点论断和且仅一个支撑视觉（chart、ranking 或 quote）。并列 KPI tiles、side-by-side metric grids、三个互相竞争的焦点数字属于 dashboard，不属于 campaign report。
一个成功页面让读者带走三件事：headline number、它背后的原因、以及它意味着什么。
Archetype names 只是内部规划标签。可见 eyebrows、captions 和 labels 必须来自主题、周期、数据角色或业务含义，而不是 section archetype names。

### 范围

范围：可滚动的单页数据叙事，其中数字是主角。

氛围：信息密度 Low → High（节奏控制）· 视觉节奏 Strong alternation（每个 section 使用不同 archetype）· 叙事弧 Beginning → Middle → End。

支持的数据形态：time-series · proportions · paired metrics · ranking · grouped metrics · event sequence · peer catalog · comparison。

### 语气与文案

页面文案读起来像策展人的墙文 — 简短、第三人称、观察式。

- Voice：第三人称观察式。只有在 attribution 中使用 `we`；绝不直接称呼读者为 `you`。
- 写陈述，不写召唤：写 `Bookings closed at 142,300`，不要写 `We booked 142,300!` — campaign report 是只读 artifact。
- Eyebrows：uppercase、mono、`tracking-[0.14em]`。Titles：sentence case，不加句末句号。Body：sentence case，完整句子，句末标点。
- 文案中的数字：tabular figures，千分位分隔，不做小数补零。
- 周期字符串使用 `·` middle dot（U+00B7），两侧各一个空格。

### 语气 — 风格注释

文案语域：confident report — 用短主张句作为章节标题，用段落长度的 subtitle，陈述结果。章节标题中文 5-14 字 / 英文 4-9 词，`font-medium` sans。Eyebrow tracking `0.16em`。抵抗 slogan、问题句、ALL-CAPS。绝不使用 `携手共创未来` / `让我们一起` / `开启新篇章`。

## 11. Section Archetype Library

一个 section = **archetype**（是什么）+ **composition treatment**（布局方式）+ **dominant move**（视线主导动作）。

### 11.1 Composition Treatments

| Treatment | 逻辑 | 密度 |
|-----------|-------|---------|
| **Full-bleed Monolith** | 一个元素填满画面并居中 | spacious |
| **Asymmetric Split** | 两个不等宽列（3:2 / 2:1） | medium |
| **Stacked Band** | 全宽 band 纵向堆叠 | medium-dense |
| **Matrix Grid** | 等尺寸 cells N×M，由叙事绑定 | dense |
| **Proportion Rail** | 连续的 parts-of-whole 轨道 | medium |
| **Offset Frame** | 打破 grid：裁切/偏心/溢出 | medium |
| **Sequence Track** | 阶梯式：index → title → note | medium-dense |
| **Typographic Field** | 只有文字，没有 panels 或 chrome | spacious-medium |
| **Annotation Rail** | 主体 (3/4) + 窄 rail (1/4) | medium |

偏好：Full-bleed Monolith（Hero, Outro）、Matrix Grid（KPI Cluster）、Stacked Band、Asymmetric Split。

### 11.2 Dominant Move

| Move | 类型 |
|------|-------|
| Scale jump（焦点 ≥ 大 2 个层级） | steady |
| Single stroke（单条线/强调） | steady |
| Path reveal（曲线绘制 / rail 填充） | steady |
| Crop / bleed | disruptive |
| Offset placement | disruptive |
| Column break | disruptive |

优先用 scale jump 和 single stroke。Disruptive 每页 ≤ 1 章。

### 11.3 Archetypes

**Hero Monolith** — 开场锚点。Treatments：Asymmetric Split **（默认，editorial masthead）** · Full-bleed Monolith · Typographic Field。

**Time Series** — 随时间变化的数值。Treatments：Stacked Band **（默认）** · Asymmetric Split。使用裸 recharts `AreaChart`/`LineChart` 放在 `<ResponsiveContainer>` 中，自定义 `<ChartTooltipCard>`（§17）。

**Proportion Field** — parts-of-whole。Treatments：Proportion Rail **（默认）** · Stacked Band。不使用 donut/pie/ring。使用裸 recharts 横向 `BarChart` + `<LabelList>`，或 shadcn `Progress`。

**Comparison** — 两个指标对比。Treatments：Asymmetric Split **（默认）** · Stacked Band。左右同字号（`text-[56px] md:text-[80px] lg:text-[104px]`）；层级由颜色建立 — leading 使用 `--primary`，trailing 使用 `--foreground-3`。Grid `items-start`。

**Ranking / List** — 按量级排序的项目。Stacked Band（≤ 5）· Matrix Grid（≥ 6）。top-1 做 scale jump。使用 list typography，绝不使用 recharts `BarChart`。

**Grouped Metric Cluster** — 并列指标，一个论断。**Matrix Grid 2×2/2×3**：CSS `grid gap-1`、`bg-surface-l2 rounded-[16px] p-6 md:p-8`，无 border/shadow；cell `h-full`，note `mt-auto`；hover `whileHover={{ y: -2 }}` 0.28s。

**Sequence / Timeline** — 按时间排序的事件（不是数值）。默认 Sequence Track。**Horizontal Timeline** alt（desktop ≥ md）：3-5 列 grid，余烬色描边圆点（10×10，1.5px `--primary` border，`--background` fill），1px `--border-strong` 发丝线连接。每个节点下方：mono ember kicker · title · body。**Mobile fallback (< md)：Vertical Timeline，左对齐** — 折叠为单列；把发丝线旋转 90°，变成左侧 1px `--border-strong` 垂直 rail（距 container 左侧约 7px）；余烬圆点（14×14，1.5px `--primary` border，`--background` fill）居中落在 rail 上；每个 milestone 的内容（mono ember kicker · title sans medium · body）位于 rail 右侧，**左对齐，并与圆点基线起点对齐 — 绝不居中对齐**。移动端垂直布局使用 shadcn `Item` + `ItemGroup`。

**Peer Set / Catalog** — 同类 peer 集合。默认 Matrix Grid。Shadcn `Card`（border-0 shadow-none p-0）。

**Quote Interstitial** — 叙事停顿。Typographic Field。SVG L-shape brackets（40×40，1px primary 0.6 opacity）。一句话 ≤ 28 words，Quote 尺度 `font-normal` — 不使用 italic，不使用 left border。

**Outro Reverent** — 报告结尾。Typographic Field。`OutroSignature` component（§17）。可选 — 只有存在 closing claim 时才输出。

## 12. 构图

默认：Hero → evidence chapters → optional Outro。Section 数量由数据决定；在出现 filler 前停止。这个风格偏好 7-9 个章节，段落驱动。

### 12.1 节奏

1. **密度轮换** — 相邻 section 必须不同（dense/medium/spacious）；不能连续两个 dense。
2. **Treatment 多样性** — 不能连续两个相同 treatment 或 archetype。
3. **Bold-move 预算** — disruptive ≤ ceil(N × 0.25)。此风格整体偏低。
4. **Break cadence** — ≥ 1 个 section 使用 Full-bleed、Offset 或 Typographic Field。Hero + Outro 可满足。

### 12.2 规则

全章节保持一致 ground；通过 density、hairlines、ember position 变化节奏。章节标记：`01` `02` `03`，ChapterStamp 每页最多 3 次。每个非 Hero 章节都用 `ChapterBanner` 开场。`ChapterDivider` 用于章内休止，克制使用。

## 13. Section Anatomy

### 13.1 Hero Monolith

焦点：primary-value Display Number，`Geist Variable` `font-medium` `--primary` 余烬色，unit suffix 使用 `--primary-hl`，animated count-up。背景：双层 shader（§17）— fixed ground `StaticMeshGradient` + Hero anchor `GrainGradient`（`offsetY={0.18}`，viewport-paused）。两者之上叠 `--ember-wash` CSS radial，约 18% alpha。

构图 — Asymmetric Split（默认）：`grid-cols-1 lg:grid-cols-[1fr_auto] lg:gap-x-16 items-start`。左侧：eyebrow（`{topic} · {period}` Meta mono `tracking-[0.16em]` `--foreground-2`）→ hero title（Hero Title 尺度 `font-medium` `--foreground` 左对齐 `max-w-[20ch]`，使用 middle dot separator 的单行多分句）→ subtitle（Lead Paragraph `font-normal` `--foreground-3` `max-w-[52ch]`）→ focal block（label Caption `--foreground-3` + AnimateNumber `--primary` 余烬色 + unit `--primary-hl` + DeltaIndicator）。右侧：metadata masthead `hidden lg:flex flex-col items-end gap-10` — ISSUE/PAGES/AUDIT/AUTHOR mono uppercase `tracking-[0.18em]` `--foreground-3` labels + `--foreground` values。

Hero 余烬标记：焦点数字、delta indicator、shader breath。底部不放 signature line。

替代：Full-bleed Monolith（居中）、Typographic Field（非数字锚点）。

Anti-refs：**Don't** 把 Hero 设在高饱和暖橙底上。**Don't** 使用产品照片。**Don't** 在 Hero 中堆 banners 或 KPI grids。**Don't** 让余烬色搭配第二个热强调色。

Primary-value 选择：(1) rate/percentage → avg，(2) aggregate keyword → sum，(3) primary metric → max，(4) same → avg。缺失时省略 Hero。

| Data Shape | Archetype |
|------------|-----------|
| Report-level anchor | Hero Monolith |
| Time-ordered series | Time Series |
| Parts-of-whole | Proportion Field |
| Two contrasting values | Comparison |

## 15. 功能状态

- **Loading**：skeleton 只替换依赖数据的槽位。静态 section structure、Hero shader 和 chapter markers 保持可见。
- **Empty**：section frame + 居中的 "暂无可用数据"，使用 `--foreground-3`。
- **Error**：frame + retry icon + "加载失败" + retry button，使用 `--foreground-2`。

## 16. Do's and Don'ts

Do：交替使用 archetypes。保持一致 ground；通过 density/hairlines/ember position 改变节奏。每个 section 一个焦点。跳过缺失数据的 section。可见 labels 来自 topic/period/metric/business meaning。

- **Don't** 在可见 UI 中显示 archetype names。
- **Don't** 使用均等 3-col grids、sidecar KPI stacks，或不能支撑一个论断的 Matrix。
- **Don't** 固定 section heights；高度由内容决定，只设置 min-height。
- **Don't** 在一个 section 中显示多个 primary numbers。Legends 与 charts 分离。
- **Don't** 使用 donut/pie/ring charts — proportion 用 rail 或 band。
- **Don't** 重复相同圆形 markers。不要到处套用同一种 reveal。
- **Don't** 显示超过 5 个未截断 ranking items。允许水平滚动。
- **Don't** 使用 emoji。不要添加 CTA/action buttons、"view more"、dashboard/marketing verbs、second-person imperatives。
- **Don't** 在没有 closing claim 时强行加入 outro。

Light-mode：overlays/skeletons 使用 `--surface-l2` 或 `--ember-wash`。不要 vignettes。

**AnimateNumber** (motion-plus/react) — Per-digit scroll。`{number || 0}` 触发 roll。Children 必须是**纯数字字符串**（无逗号，无符号）。Bitable 格式化值如 `"¥1,234,567.00"` 或 `"85%"` 会变成 NaN — 先用 `parseDisplayValue()` 拆分。Reduced motion：纯文本。

```tsx
import { AnimateNumber } from "motion-plus/react";

// 拆分 Bitable 格式化值 → prefix / 纯数字 / suffix
function parseDisplayValue(value: string | undefined) {
  if (!value) return { prefix: "", number: "0", suffix: "" };
  const match = value.match(/^([^\d\-]*?)(-?[\d,]+\.?\d*)(.*)$/);
  if (!match) return { prefix: "", number: "0", suffix: "" };
  return {
    prefix: (match[1] ?? "").trim(),
    number: match[2].replace(/,/g, ""),  // 去掉逗号
    suffix: (match[3] ?? "").trim(),
  };
}

// 用法："¥1,234,567.00" → prefix="¥", number="1234567.00", suffix=""
//       "85%" → prefix="", number="85", suffix="%"
const { prefix, number, suffix } = parseDisplayValue(row["sum(fldRevenue)"]?.value);
<span className="inline-flex items-baseline gap-1 whitespace-nowrap">
  {prefix && <span style={{ color: "var(--primary-hl)" }}>{prefix}</span>}
  <AnimateNumber
    style={{ color: "var(--primary)" }}
    transition={{ type: "spring", duration: 2.0, bounce: 0 }}
  >
    {number || 0}
  </AnimateNumber>
  {suffix && <span style={{ color: "var(--primary-hl)" }}>{suffix}</span>}
</span>
```

**Recharts** (recharts) — 所有图表使用裸 recharts。Series colors 直接来自 `var(--chart-1)` 到 `var(--chart-5)`。

```tsx

**Bar chart fill 必须显式设置到每一个 Bar 上 — recharts 默认 Bar fill 是纯黑色（`#000`），省略 `fill` 会生成整块黑色图表。** 单色 series 直接在 `<Bar>` 元素上用 `fill="var(--chart-N)"` 设置 token fill；如果每个 data point 颜色不同，则使用 `<Cell>` children。绝不依赖 recharts 默认 fill，绝不使用 Tailwind 调色板，绝不使用 hex literal — 始终使用 `var(--chart-1)` 到 `var(--chart-5)` tokens。Highlighted / latest bar 使用 `var(--chart-1)` 余烬色；prior bars 递进到 `var(--chart-3)` 到 `var(--chart-5)` 暖中性色。

**BarChart Tooltip cursor 必须显式设置** — recharts BarChart cursor 默认是填充矩形，在某些版本或 theme context 中可能渲染为 `#000` 纯黑。使用 `cursor={{ fill: 'var(--chart-hover)' }}` 应用暖中性色 hover token，或用 `cursor={false}` 完全禁用 cursor highlight，仅依靠 `<ChartTooltipCard>` 提供 hover feedback（更适合 editorial restraint 风格 — 视觉干扰更少）。绝不依赖 recharts 的 BarChart 默认 cursor。

  return (

      <motion.span initial={{ scaleX: 0 }} whileInView={{ scaleX: 1 }}
        viewport={{ once: true, margin: "0px 0px -10% 0px" }}
        transition={{ duration: 1.0, ease: EASE.out, delay: 0.7 }}
        className="block h-px w-32 md:w-40 origin-right" style={{ background: "var(--primary)" }} />
      <motion.span initial={{ rotate: 0, opacity: 0 }} whileInView={{ rotate: 45, opacity: 1 }}
        viewport={{ once: true, margin: "0px 0px -10% 0px" }}
        transition={{ duration: 0.8, ease: EASE.out, delay: 0.9 }}
        className="block size-2" style={{ background: "var(--primary)" }} />
      <motion.span initial={{ scaleX: 0 }} whileInView={{ scaleX: 1 }}
        viewport={{ once: true, margin: "0px 0px -10% 0px" }}
        transition={{ duration: 1.0, ease: EASE.out, delay: 0.7 }}
        className="block h-px w-32 md:w-40 origin-left" style={{ background: "var(--primary)" }} />
    </div>
  );
}
```
下方 Colophon：`text-[12px] font-medium uppercase tracking-[0.20em]` Mono `--foreground-3`。

**Tags** — Shadcn `Badge variant="outline"`。余烬 hover：`hover:bg-[color:var(--ember-wash)]`。

## 18. Component Constraints

使用 top-level hooks、typed props、`motion/react`、`motion-plus/react`、numeric easing arrays；装饰性视觉使用 `aria-hidden`；可读数值提供 semantic labels；Recharts 始终设置 `isAnimationActive={false}`；AnimateNumber、WebGL、spotlight 和离屏连续动效都必须有 reduced-motion fallback。
